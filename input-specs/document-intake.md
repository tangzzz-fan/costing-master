# 混合文件输入规范

## 适用场景

当用户一次上传合同、招标文件、清单、图纸、签证、材料价格、付款和结算等多类型文件时，先用本规范建立文件清单和证据索引，再进入对应 workflow。

## 文件清单必填字段

| 字段 | 说明 |
|---|---|
| 文件名 | 原文件名，不改名 |
| 文件类型 | Excel/PDF/Word/图片/扫描件/DWG/DXF/邮件/其他 |
| 文件用途 | 合同/招标/清单/图纸/地质/变更/签证/材料价格/付款/结算/验收/监测 |
| 页数/工作表 | PDF 页数、Excel 工作表名、Word 段落范围 |
| 版本/日期 | 报审版/审核版/定案版/盖章版；文件日期 |
| 签章状态 | 原件/复印件/盖章/签字/未签章/无法判断 |
| 可读性 | 可读/部分可读/扫描需 OCR/加密/损坏 |
| 关联问题 | 对应审核问题编号或台账行 |

## 通用抽取字段

- 项目基本信息：项目名称、地点、标段、合同类型、适用标准。
- 金额字段：合同价、清单合价、变更金额、材料调差、付款、扣款、质保金。
- 时间字段：合同日期、招标日期、变更/签证日期、付款日期、结算日期。
- 证据字段：文件名、页码/行号/工作表、条款号、清单编码、签证编号、附件名。
- 签认字段：签字人、签字日期、盖章、监理/发包人确认。

## 引用格式

- PDF：`文件名 + 第 X 页 + 条款号/表格行`。
- Excel：`文件名 + 工作表名 + 行号/单元格`。
- Word：`文件名 + 条款号/段落号`。
- 扫描件/图片：`文件名 + 页码/图号 + OCR/人工摘录`。
- DWG/DXF：`文件名 + 图层/图号 + L1/L2 能力说明`。

## OCR 与扫描件

- OCR 结果必须标注“OCR 识别，需人工核对”。
- 数字、日期、金额、签字和印章是高风险字段，必须复核。
- 无法识别的页/字段写入需补资料或人工确认，不猜测。
- 扫描件没有签章页或附件时，不能按原件处理。

## 版本与重复文件

- 记录报审版、审核版、定案版、盖章版和扫描版。
- 同一文件名不同内容时，列出版本冲突，请用户确认有效版本。
- 不默认最新文件就是有效版本；以合同约定和签认记录为准。

## 缺资料时的追问

- 请提供合同专用条款、招标文件、清单、图纸和地勘资料。
- 请提供变更/签证原件、书面指令、时效证明和附件。
- 请提供信息价期别、询价单、采购合同或发票。
- 请提供付款台账、预付款扣回、质保金台账和结算书。
- 请说明文件版本、签章状态和是否有 OCR 需求。

## 安全与保密

- 只提取审核必需字段，不扩散无关个人信息和商业秘密。
- 第三方 OCR、CAD 脚本或在线工具需用户确认，不自动上传项目文件。
- 对外提交前按项目保密要求脱敏。

## 禁止直接推断

- 不得编造文件内容、页码、条款号、签字人、金额或日期。
- 不得把会议纪要当成书面指令，不得把复印件当成原件。
- 不得在文件无法读取时假装已核对。
- 不得把文件存在等同于内容已核实。
