# 地铁/轨道交通清单输入规范

## 支持文件格式

- `.xlsx`、`.xls`、`.csv`，以及广联达、鲁班、斯维尔等软件导出的地铁清单/计价表。
- 常见工作表：单位工程汇总表、分部分项工程量清单、措施项目清单、其他项目清单、增值税表、人材机汇总表、工程量计算书。
- 地铁项目通常按标段、工区、车站、区间分册；先确认文件属于哪个标段/工区。

## 必提字段

| 字段 | 说明 |
|---|---|
| 标段/工区 | 如 VIII-TS-08 标、某站、某区间 |
| 单位工程 | 车站主体、附属结构、盾构区间、联络通道、交通导改等 |
| 专业/工法 | 明挖、盖挖、盾构、矿山法、冻结法等 |
| 清单编码/名称 | 地铁清单编码和项目名称 |
| 项目特征 | 墙厚、桩径、混凝土强度、抗渗、盾构直径、管片环宽等 |
| 单位/工程量 | m、m²、m³、t、环、项；注意单位与项目名称匹配 |
| 综合单价/合价 | 用于校验工程量乘单价 |
| 结构部位 | 车站主体、出入口、风亭、区间、始发/接收井 |
| 依据字段 | 定额/消耗量编号、信息价期别、询价来源、地质资料 |

## 车站清单必查特征

- 地下连续墙：墙厚、槽深、混凝土强度/抗渗、接头形式、导墙、钢筋笼、泥浆、入岩、检测。
- 钻孔灌注桩：桩径、桩长、持力层、混凝土、泥浆、钢筋笼、检测、空桩。
- 土方开挖：土类别、开挖深度、支撑、降水、运距、弃土/回填、工作面/放坡。
- 主体结构：混凝土强度/抗渗、部位、泵送、施工缝/后浇带、模板、钢筋。
- 防水：材料、厚度、道数、部位、保护层、变形缝/施工缝。
- 交通导改、管线迁改：范围、期限、次数、权属、迁移/恢复方式。

## 盾构清单必查特征

- 盾构掘进：盾构类型/直径、地质条件、掘进长度、埋深、换刀、同步注浆、出土/泥浆、穿越建构筑物/既有线、监测。
- 管片：环宽、直径、厚度、混凝土强度/抗渗、配筋、防水、螺栓、预埋件。
- 端头加固：加固方式、范围、降水、洞门凿除、密封。
- 联络通道：工法、支护、防水、监测。
- 始发/接收井：围护、土方、结构、端头加固、洞门。

## 常见异常

- 车站、区间、附属结构混在同一单位工程，导致工程量重复或漏项。
- 管片按“环”和按“m”混用，未说明环宽和负环/楔形环。
- 地连墙按“m²”和“m³”混用，未说明墙厚和槽深。
- 土方开挖未区分土类别、支撑、降水和运距。
- 交通导改、管线迁改与措施项目或暂列金额重复。
- 监测项目未列或只写“按规范”。
- 盾构掘进未描述地质条件、穿越风险和换刀。
- 综合单价与合价不闭合，或工程量小数位异常。

## 大型文件处理

- 先按标段/工区/车站/区间分组，再按金额占比排序。
- 金额占比 > 70% 的车站或区间优先复核。
- 同一清单编码跨 sheet 重复出现时，统一核查是否为同一项目。
- 先读汇总表和措施/其他项目表，再读分部分项明细。

## 缺资料时的追问

- 请提供标段/工区划分、车站和区间清单、设计图纸、地质资料。
- 请提供项目所在地城市轨道交通计价表/消耗量、费用文件和信息价期别。
- 请说明合同类型、措施项目包干范围、交通导改和管线迁改的责任界面。
- 请提供变更签证原件、监测方案、穿越审批和施工记录。

## 禁止直接推断

- 不得凭空补清单编码、定额编号、工程量、综合单价或地质条件。
- 不得用房建单方指标替代地铁车站/盾构造价。
- 不得在没有图纸和地质资料时承诺完整算量或漏项检查。
