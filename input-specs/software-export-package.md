# 计价软件导出包输入规范

> 适用于广联达 GCCP/GBQ、新点、斯维尔、品茗、鲁班、算王等计价软件导出的清单、报价和结算表。
>
> 本规范只处理软件导出的 Excel/CSV；不读取或修改软件专有源文件。

## 一、支持的文件格式

| 格式 | 支持情况 | 说明 |
|---|---|---|
| `.xlsx` | 直接读取 | 推荐；保留工作表名和行号 |
| `.xlsm` | 直接读取 | 按 xlsx 结构处理；宏不执行 |
| `.csv` | 直接读取 | 支持 UTF-8 BOM、GB18030/GBK、UTF-16 和逗号/制表符分隔 |
| `.xls` | 需转换 | 在 Excel/WPS 中另存为 `.xlsx` 或 CSV |
| `.GBQ`、`.GCCP` | 不读取 | 软件专有文件；请在软件中导出 Excel |
| `.24jz`、`.24jk`、`.24jt` | 不读取 | 江苏电子招投标数据交换文件；由软件/平台 XSD 校验 |

## 二、最小导出包

一份可复核的软件导出包至少包含：

| 资料 | 用途 | 是否必需 |
|---|---|---|
| 项目设置截图或说明 | 地区、定额库、费用文件、税率、计税方式、计价模板 | 必需 |
| 分部分项工程量清单计价表 | 清单五要素、工程量、综合单价、合价 | 必需 |
| 单位工程费汇总表 | 分部分项、措施、其他项目、增值税汇总 | 必需 |
| 单价措施项目清单计价表 | 单价措施清单项和措施工程量 | 项目有单价措施时必需 |
| 总价措施项目清单计价表 | 安全文明施工、夜间施工、扬尘防治等费率 | 项目有总价措施时必需 |
| 其他项目清单计价表 | 暂列金额、暂估价、计日工、总承包服务费 | 项目有其他项目时必需 |
| 人材机汇总表 | 材料价格来源、甲供材、暂估材、主材异常 | 建议 |
| 综合单价分析表 | 人工、材料、机械、管理费、利润、风险费 | 重点清单项建议 |
| 定额子目明细表 | 区分清单工程量和定额工程量、检查套项和换算 | 组价复核时必需 |
| 发包人提供材料一览表 | 甲供材扣回和总承包服务费 | 项目有甲供材时必需 |

缺少项目设置、清单计价表或费用汇总表时，应先输出《需补资料清单》，不得用默认地区、默认费率或默认税率补齐。

## 三、表头识别与字段别名

脚本 `scripts/check_software_export.py` 自动识别常见的表头别名；不同软件、版本和导出模板可能不同，以实际导出为准。

| 规范字段 | 常见别名 |
|---|---|
| 序号 | 序号、序、No |
| 项目编码 | 项目编码、清单编码、编码、项目编号、清单编号、清单项目编码 |
| 项目名称 | 项目名称、清单名称、名称、子目名称 |
| 项目特征 | 项目特征、项目特征描述、特征描述、特征 |
| 计量单位 | 计量单位、单位、单位名称 |
| 工程量 | 工程量、数量、清单工程量、工程数量、计算工程量 |
| 综合单价 | 综合单价、单价、全费用综合单价 |
| 合价 | 合价、金额、总价、合计金额 |
| 暂估价 | 暂估价、其中暂估价、暂估单价 |
| 定额编号 | 定额编号、定额号、子目编号、定额子目编号 |
| 备注 | 备注、说明 |

表头可以位于标题行、项目名称行和页码行之后；脚本会在前 30 行内寻找得分最高的表头，并支持两行合并表头。建议导出时保留原始标题行和工作表名，便于定位。

## 四、软件差异和导出要点

| 软件 | 常见导出特点 | 建议 |
|---|---|---|
| 广联达 GCCP/GBQ | 分部分项、措施、其他项目、人材机、综合单价分析分表；可能保留“规费税金”旧模板 | 导出全部工作表；保留项目设置截图；2024 版项目核对规费和增值税口径 |
| 新点/国泰新点 | 电子招标接口和清标接口；江苏 24 版数据交换 | 先导出 Excel 体检，再由软件生成 `.24jz/.24jk/.24jt` |
| 斯维尔 | 广东/深圳地区使用较多；表头可能含地方习惯字段 | 核对地区定额和费用文件；必要时另存 CSV |
| 品茗/鲁班/算王 | 表头、合并单元格和隐藏列差异较大 | 用 `--template` 查看规范表头；保留原始导出，不手工删列 |
| Excel/WPS 手工整理 | 合并单元格、隐藏行、公式覆盖、文本格式编码 | 保持原始数据 sheet，计算另设 sheet |

导出时建议：

1. 勾选“导出全部工作表”或“按表导出”，不要只导出屏幕可见区域。
2. 保留项目编码、项目名称、项目特征、计量单位、工程量、综合单价、合价、暂估价列。
3. 项目编码列设为文本，避免 12 位编码丢前导零。
4. 不要删除隐藏列、公式列或项目设置页；如必须删除，在导出说明中注明。
5. 保留金额和工程量的小数位；不要为了“看起来整齐”手工四舍五入。
6. 导出后先另存一份原始版本，再在副本上整理。

## 五、江苏电子招投标数据交换（2026-06-01 起）

江苏省《建设工程电子招标投标造价数据交换标准》自 2026-06-01 起执行，替代原《建设工程电子招投标专业工具软件数据交换标准》（DGJ32/TJ 93-2016）。与计价软件导出直接相关的要点：

| 文件后缀 | 用途 | 说明 |
|---|---|---|
| `.24jz` | 招标工程量清单 | 由招标人或其委托的计价软件生成 |
| `.24jk` | 最高投标限价 | 与招标清单配套 |
| `.24jt` | 投标报价 | 由投标人的计价软件生成 |

关键规则：

- XML 文件头为 `<?xml version="1.0" encoding="utf-8"?>`；版本字段 `Version` 固定为 `4.0`。
- 文件应通过《江苏省建设工程电子招标投标造价数据交换标准.XSD》校验。
- 清单工程量最多 6 位小数；金额最多 2 位；费率最多 4 位；人材机单价最多 4 位。
- 费率、风险系数按百分比存储，例如存储 `10` 表示 `10%`。
- 招标文件和投标文件应对单项工程、单位工程、分部工程清单、措施项目、其他项目、暂列金额、暂估价、计日工、总承包服务费、材料暂估单价、甲供材、调差材料、增值税税率等做一致性校验。
- 专业工具软件应去除不可见字符和空格；必填字段不得为空。
- 分部分项工程项目费=清单项明细合计；综合合价=综合单价×数量；单位工程总价应扣除发包人提供材料费（不含保管费）。

本 Skill 不直接解析 `.24jz/.24jk/.24jt`；上述规则用于指导 Excel 导出体检、人工核对和平台校验前的准备。正式投标、清标和评标以交易平台、软件 XSD 校验和评标委员会为准。

## 六、文件命名和版本记录

建议命名：

```text
项目简称_标段_专业_表类型_软件版本_导出日期_版本号.xlsx
```

示例：

```text
苏州某项目_一标段_土建_分部分项清单_GCCP6_20261031_v1.xlsx
```

每次修改后保留新版本，不覆盖原始导出；在 `templates/software-issue-return-list.md` 或 `templates/evidence-index.md` 中记录文件名、导出时间、软件版本、修改人和复核人。

## 七、保密和平台边界

- 未公开的招标文件、最高投标限价、投标报价、合同、供应商报价和成本数据，不得上传到未经企业批准的公共 AI 环境。
- 上传前脱敏项目名称、投标人名称、联系人、电话、身份证号、银行账号等个人信息和商业敏感信息。
- 使用企业认可的本地部署、私有云或已签署保密协议的 AI 工具。
- 投标文件加密、CA 签章、上传和平台接收由投标制作工具和交易平台完成，Skill 不替代这些操作。
- 不把 Skill 生成的体检报告直接作为投标文件、清标结论或评标依据；必须由专业人员复核。

## 八、常见导出问题和处理

| 问题 | 影响 | 处理 |
|---|---|---|
| 项目编码被 Excel 当作数值，丢失前导零 | 编码位数不足、清标无法对应 | 将编码列设为文本后重新导出 |
| 合并单元格导致清单编码只出现在首行 | 子行被识别为缺编码 | 导出明细表或在软件中取消合并 |
| 一个工作表放多张清单表 | 只识别第一张表，后续表未处理 | 按表拆分导出或使用多 sheet |
| 清单量和定额量混在同一列 | 量价检查误报或漏报 | 使用定额子目明细表，区分清单量和定额量 |
| 综合单价只显示 2 位，合价按未显示精度计算 | 量价乘积出现小数差异 | 核对软件单价精度和导出小数位，标记人工确认 |
| 隐藏行、隐藏列或筛选状态 | 汇总和明细不一致 | 取消隐藏、清除筛选后重新导出 |
| 2024 版模板仍保留“规费税金”表 | 费用口径混用 | 核对项目适用标准和软件计价模板 |
| 金额列是公式但导出为文本 | 无法计算或合计 | 检查公式、单元格格式和导出设置 |

## 九、缺资料时的追问

- 请提供软件名称、版本、地区、定额库、费用文件和计税方式。
- 请提供项目设置截图或导出说明。
- 请提供分部分项、措施、其他项目、人材机和费用汇总表。
- 请说明导出表是招标清单、最高投标限价、投标报价、预算还是结算。
- 请提供项目适用标准版本、招标/合同日期和项目所在地。
- 江苏 2024 版项目请说明 `.24jz/.24jk/.24jt` 的生成软件和平台校验结果。

## 十、禁止事项

- 不得凭空补清单编码、项目特征、定额编号、综合单价、费率或工程量。
- 不得直接修改招标人提供的清单项、暂列金额、暂估价、税率和安全生产措施费费率。
- 不得把自动体检结果写成评标结论、废标结论、低于成本认定或法律意见。
- 不得把公开样例、模拟数据或历史项目数据当作当前项目数据。
