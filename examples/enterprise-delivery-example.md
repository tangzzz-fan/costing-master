# 示例：企业级交付与审核记录

## 用户提示词

```text
请把苏州地铁 VIII-TS-08 结算审核整理成内部送审包。
AI 负责整理工作底稿和证据索引；复核人由企业造价工程师担任，成本负责人和项目负责人由企业指定。
先做内部审核，不对外交付，不要把 AI 写成签认人。
```

## 角色分配

| 角色 | 人员 | 职责 | 签认边界 |
|---|---|---|---|
| 编制人 | AI Agent（工作底稿） | 整理报告、台账、证据索引和质检建议 | 不签认、不盖章 |
| 复核人 | 企业造价工程师 | 独立复核证据、计算、标准适用和结论 | 签署复核记录 |
| 成本负责人 | 企业成本负责人 | 复核商业影响和处置方案 | 签署成本意见 |
| 项目负责人/授权人 | 企业项目负责人 | 决定是否对外交付 | 授权签认/签章 |
| 法务/合规 | 按需 | 合同和法律风险 | 法务/合规意见 |

## 审核记录摘要

| Gate | 结果 | 说明 |
|---|---|---|
| G1 资料完整性 | 需补资料 | 合同、清单、地勘、签证、付款和监测资料未提供 |
| G2 证据和计算 | 通过 | 公开事实和模拟计算分列，计算闭合 |
| G3 标准和地方适用 | 通过 | 按合同签订日 2020-05-18 划断，GB 50500-2013 + L00 江苏/苏州；2024 版仅作对照 |
| G4 结论和风险 | 通过 | 未出最终审定价，疑似/待补单列 |
| G5 交付包和兼容 | 通过 | 交付包齐全，CI 七步通过 |
| G6 签认和对外交付 | 仅内部 | 未获对外交付授权 |

## 验收要点

- AI 没有被写成签认人或注册造价工程师。
- 交付状态是内部送审稿，不是定案稿。
- 交付包、审核记录、证据索引、质检摘要和修订记录齐全。
- 缺失资料和结论强度如实标注。
- 对外交付前必须补充人工授权和签认。
