> 测试性质：文档级 dry run，使用公开项目框架加模拟合同、清单、变更、材料价格、进度款和结算数据。

## 一、测试目的

- 材料调差计算和依据检查。
- 进度款审核和扣回计算。
- 结算审核、问题台账、管理层摘要和二次审核。

## 三、测试执行结果

### 3.1 进度款审核

输入：本期申报已完产值 80,000,000 元，其中未确认签证 2,000,000 元；累计已完产值 300,000,000 元；合同价 30% 节点为 280,431,409.08 元。

```text
本期可计入已完产值 = 80,000,000 - 2,000,000 = 78,000,000 元
本期进度款 = 78,000,000 × 80% = 62,400,000 元
预付款扣回 = 62,400,000 × 20% = 12,480,000 元
质保金扣留 = 62,400,000 × 3% = 1,872,000 元
建议本期支付 = 62,400,000 - 12,480,000 - 1,872,000 = 48,048,000 元
```

结果：计算闭合；未确认签证已排除；预付款扣回节点判断正确；质保金基数正确。需要补监理确认、付款台账和预付款扣回记录。

### 3.2 变更签证审核

| 编号 | 测试判断 | 依据/缺口 |
|---|---|---|
| V-001 地下连续墙超深 | 疑似/待确认 | 有指令和地质记录，但需核对超深工程量、地质责任和计量口径 |
| V-002 盾构孤石处理 | 疑似/待确认 | 有地质记录和监理签认，但需补充孤石位置、处理方案、台班和材料记录 |
| V-003 交通导改 | 疑似重复 | 合同措施项目可能已包含交通导改，需核对合同范围和现场实际 |
| V-004 管线迁改 | 待补/证据不足 | 仅会议纪要，无发包人书面指令，超过 14 天申报时限 |

结果：未把 V-003/V-004 写成确定审减或确定无效；分级符合 Skill 规则。

### 3.3 材料调差

| 材料 | 有依据的调差金额(元) | 测试判断 |
|---|---:|---|
| 螺纹钢 HRB400 Φ16-25 | 1,950,000 | 4,500 - 4,000×1.05 = 300 元/t，×6,500 t |
| 商品混凝土 C40 | 420,000 | 540 - 500×1.05 = 15 元/m³，×28,000 m³ |

| 防水卷材 | 无法计算 | 合同未明确可调，缺信息价/报价 |

结果：只确认有合同和信息价依据的 2,370,000 元；其余列为待补资料/合同确认。未使用全国参考价替代苏州市工程造价信息。

### 3.4 结算审核

| 问题 | 测试判断 |
|---|---|
| 报审总额 1,050,000,000 元与组成合计 1,024,771,363.61 元存在 25,228,636.39 元未说明差异 | 确定问题/需修正汇总 |
| V-003 交通导改 500,000 元疑似重复 | 疑似/待确认，不计入确定审减 |
| V-004 管线迁改 300,000 元缺书面指令和时效 | 待补/证据不足，不计入确定金额 |
| 材料调差 20,000,000 元中约 17,630,000 元缺依据 | 待补/需核减依据 |
| 索赔 10,000,000 元缺工期影响和费用计算书 | 待补/证据不足 |
| 结算书未列明质保金 3% 扣留 | 待补/需修正 |
| 地连墙、盾构掘进、管片等清单特征不完整 | 疑似/需补特征，可能影响综合单价 |

结果：未给出最终审定价；确定问题、疑似问题、待补资料和人工确认已分列；第二层审核应判定“工作底稿，不可交付签章”。

### 3.5 清单特征检查

10 项样本均发现特征缺失：

- 地下连续墙缺槽深、接头形式、导墙、钢筋笼。
- 钻孔灌注桩缺桩长、持力层、泥浆、检测要求。
- 土方开挖缺土类别、运距、支撑、降水。
- 主体结构混凝土缺抗渗、泵送、部位、施工缝。
- 钢筋缺规格、连接方式、措施筋、抗震。
- 防水缺厚度、道数、部位、保护层。
- 盾构掘进缺地质条件、掘进长度、换刀、同步注浆。
- 管片缺环宽、配筋、防水、螺栓。
- 交通导改、管线迁改缺范围、期限、权属和恢复方式。

结果：通用清单检查规则能发现“特征缺失”，但 `references/boq-check-rules.md` 没有地铁车站/盾构专项清单规则，属于 v0.7.0 需要补齐的能力缺口。

## 四、测试结论

| 测试项 | 结果 |
|---|---|
| 进度款计算与扣回 | 通过 |
| 未确认签证处理 | 通过 |
| 变更签证证据分级 | 通过 |
| 材料调差只认有依据金额 | 通过 |
| 结算总额闭合检查 | 通过 |
| 结论强度控制，不出最终审定价 | 通过 |
| 第二层审核阻断无依据交付 | 通过 |
| 地铁车站/盾构清单专项检查 | 部分通过，缺专项规则 |
| 苏州地铁专项定额/指标/价格来源 | 缺口 |
| 地铁合同风险、索赔、监测、交通导改规则 | 缺口 |

总体判断：现有通用工作流可以完成地铁场景的进度款、变更签证、材料调差和结算审核，并保持“证据不足不交付”的边界；但地铁车站/盾构的专项清单、定额、指标、合同风险和地区价格来源不足，不能宣称具备完整地铁造价审核能力。
