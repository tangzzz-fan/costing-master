# 苏州地铁 VIII-TS-08 造价演练包

> 用途：给 Costing Master 做一次端到端演练。包内同时包含真实官方文件、真实公开项目信息和教学模拟项目文件，覆盖资料完整性检查、标准适用判断、进度款审核、材料调差和结算审核。
>
> 边界：本包不是真实项目的审核成果，模拟数据不得用于任何实际结算、索赔或对外报告。

## 一、三类材料，先分清

| 类别 | 目录 | 可信度 | 说明 |
|---|---|---|---|
| 官方文件原件 | `01-official/html/` | 高 | 从政府官网保存的 HTML，附 URL、下载时间和 SHA256 |
| 公开项目事实 | `02-project/00-项目背景.md` | 高 | 来自苏州公共资源交易平台中标合同公示 |
| 教学模拟数据 | `02-project/` 其余文件 | 低 | 合同条款、清单、签证、进度款、调差、结算均为演练构造 |

**使用规则**：任何结论必须区分「来自官方文件」「来自公开公示」和「来自模拟数据」，不得把模拟数据写成项目事实。

## 三、四个任务

| 任务 | 内容 | 对应 workflow | 主要考点 |
|---|---|---|---|
| T1 | 资料完整性 + 标准适用判断 | `workflows/document-extraction-and-evidence.md` | 缺资料清单；2020 年签约项目该用哪版标准 |
| T2 | 第 12 期进度款审核 | `workflows/progress-payment-audit.md` | 未确认签证扣除、预付款起扣点、质保金 |
| T3 | 材料调差审核 | `workflows/material-price-analysis.md` | 风险幅度、只调幅度外、只计增值税 |
| T4 | 结算审核与审减台账 | `workflows/settlement-audit.md` | 算术差异、无依据调差、待补证据分级 |

建议顺序：T1 → T2 → T3 → T4。T1 的结论会决定 T2 至 T4 的取费口径。

## 四、怎么用

1. 把 `05-output/` 当成工作目录，按任务编号新建文件，例如 `T2-进度款审核.md`。
2. 先读 `03-tasks/` 的任务说明，再自行判断需要哪些材料；不要先看 `04-expected/`。
3. 完成后对照 `04-expected/参考结论.md` 和 `04-expected/评分表.md` 自评。
4. 需要让 Agent 演练时，直接说「用 examples/drill-suzhou-metro-viii-ts-08 做 T2」，并指定产出目录。
