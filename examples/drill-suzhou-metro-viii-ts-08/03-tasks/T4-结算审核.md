# T4 结算审核与审减台账

## 目标

对结算书做完整审核，出结算审核意见和审减/审增台账。

## 输入

- `02-project/05-结算书汇总.md`
- `02-project/03-变更签证/`（4 份）
- `02-project/02-工程量清单.csv`
- `02-project/04-进度款申请.md`（已付金额参考）
- T2、T3 的审核结论

## 要求

### 1. 结算组成核对

逐项核对合同价、变更、调差、索赔，说明组成合计与申报总额的差异处理。

### 2. 审减台账

至少覆盖以下事项，每项写明编号、事由、申报金额、审减金额、判断等级、依据、处理要求：

- 结算汇总算术差异
- 材料调差无依据部分
- 索赔缺证据
- 签证缺授权签署
- 疑似重复计量
- 质保金返还口径
- 清单特征缺项

判断等级用：确定问题 / 疑似问题 / 待补资料 / 人工确认。

### 3. 汇总

| 类别 | 金额 |
|---|---:|
| 申报结算总额 | |
| 确定核减 | |
| 待补证据（暂不核减） | |
| 审核后结算金额 | |

### 4. 结论强度

写明：

- 是否具备出具最终审定价的条件
- 哪些事项必须人工确认
- 哪些资料缺失导致结论只能到工作底稿

## 输出

`05-output/T4-结算审核与审减台账.md`。

## 自检

- 审减金额是否重复计算（算术差与无依据调差是否重叠）？
- 每个金额是否都有证据或明确标注「待补」？
- 结论是否避免了「确定违法」「最终审定」等越权表述？
