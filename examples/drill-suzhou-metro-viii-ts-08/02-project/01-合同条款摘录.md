# 合同条款摘录（教学模拟）

> 本文件为演练构造，不对应真实合同。条款编号自拟，用于练习条款定位和口径判断。

## 一、合同基本约定

| 条款 | 内容 |
|---|---|
| 合同类型 | 单价合同，工程量按实计量 |
| 合同价 | 934,771,363.61 元（含税） |
| 工期 | 1507 日历天 |
| 计价依据 | 招标文件、GB 50500-2013、江苏省 2014 版费用定额及配套文件 |
| 工程量清单 | 招标工程量清单为暂估，结算按实际完成并经确认的工程量计算 |

## 二、付款条款

| 条款 | 内容 |
|---|---|
| 预付款 | 合同价的 10%，即 93,477,136.36 元 |
| 预付款起扣点 | 累计完成产值达到合同价的 30% 起扣 |
| 预付款扣回 | 自起扣点起，按每期进度款应付金额的 20% 扣回，至扣完为止 |
| 进度款比例 | 按经确认的已完产值的 80% 支付 |
| 质保金 | 每期进度款扣留 3%，竣工结算后按约定返还 |
| 支付时限 | 收到完整申请后 28 天内支付 |

## 三、变更与签证

| 条款 | 内容 |
|---|---|
| 变更指令 | 必须以发包人或监理书面指令为准，口头指令需 7 天内补书面确认 |
| 报送时限 | 变更实施后 14 天内报送变更费用，逾期视为放弃（合同另有约定除外） |
| 计价原则 | 合同已有适用单价按合同单价；有类似单价参照类似；无适用无类似时按定额及信息价组价 |
| 签证要求 | 需发包人、监理、承包人三方签字，并附影像、测量和计算资料 |

## 四、材料价差调整

| 条款 | 内容 |
|---|---|
| 可调材料 | 钢筋、商品混凝土 |
| 风险幅度 | 5% |
| 调整范围 | 仅调整超出风险幅度部分，幅度内不调 |
| 价格来源 | 苏州市工程造价信息施工期对应期别 |
| 计算口径 | 价差只计取增值税，不计管理费、利润和措施项目费 |
| 申报时限 | 每季度末后 15 天内申报当期调差 |

## 五、索赔

| 条款 | 内容 |
|---|---|
| 索赔时效 | 事件发生后 28 天内提交索赔意向，逾期不予受理 |
| 索赔资料 | 事件事实、责任划分、工期和费用计算、授权签署、附件证据 |
| 审批 | 监理初审、发包人审定 |

## 六、结算

| 条款 | 内容 |
|---|---|
| 报送时限 | 竣工验收后 28 天内报送结算书 |
| 审核时限 | 收到完整结算资料后 60 天内完成审核 |
| 争议处理 | 协商不成按合同争议条款处理，不因争议停止已确认部分付款 |

## 七、演练提示

本合同的计价依据写的是 2013 版，与项目 2020 年签约的事实一致；不要套用 2024 版的费用组成和增值税口径。
