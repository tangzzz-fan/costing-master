# 评分表

> 总分 100 分。每个检查点按「做到 / 部分做到 / 未做到」记满分、半分或零分。

## 通用规则

| 项 | 扣分 |
|---|---:|
| 把模拟数据写成项目事实，或未标注数据来源 | −5 |
| 编造文号、标准编号、条款号或金额 | −10 |
| 未列需补资料清单 | −5 |
| 结论出现「违法」「最终审定」等越权表述 | −5 |

## T1 资料与标准（20 分）

| 检查点 | 分值 |
|---|---:|
| 需补资料不少于 5 项，按影响排序 | 5 |
| 每项写明缺失影响和责任方 | 3 |
| 结论为 GB 50500-2013 + 江苏 2014 版（L00） | 6 |
| 依据链含合同日期、2024 标准实施日、江苏/苏州 2026-06-01 和文号 | 4 |
| 对照场景给出 2024 版 + L01，并列出至少 3 点差异 | 2 |

## 常见错误

| 错误 | 后果 |
|---|---|
| 用 2024 版规则审 2020 年签约项目 | 取费口径和费用组成全部错位 |
| 预付款扣回按申报额计算 | 多扣 320,000 元 |
| 调差按全额价差计算 | 多计 17,630,000 元 |
| 把算术差异和调差核减相加时重复计算 | 审减金额虚高 |
| 把待补证据直接核减 | 结论强度过度，易引发争议 |
| 未区分合同价、变更、调差、索赔的包含关系 | 汇总不闭合 |
