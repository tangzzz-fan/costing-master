## 示例完整性清单

| 资料类别 | 状态 | 缺失/备注 |
|---|---|---|
| 合同/招标 | 部分 | 仅有公开合同金额和中标人，缺合同条款和招标文件 |
| 清单/图纸 | 缺失 | 缺工程量清单、图纸和地勘报告 |
| 变更/签证 | 缺失 | 缺书面指令、签证原件、时效和附件 |
| 材料价格 | 缺失 | 缺信息价期别和采购凭证 |
| 付款/结算 | 缺失 | 缺付款台账、预付款扣回、质保金和结算书 |
| 监测/穿越 | 缺失 | 缺监测方案、频率、报警值和穿越审批 |

## 验收要点

- 公开资料可以证明公开事实，但不能替代合同、清单、地勘和签证原件。
- 缺失资料必须列入需补资料，不得编造内容或给出确定审核结论。
- 证据索引要记录文件名、位置、可靠性和关联问题。
- 标准信息页和地区公告只能证明标准和地区规则，不能证明项目实际执行情况。
