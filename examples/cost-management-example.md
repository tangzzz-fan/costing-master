# 示例：成本管理与偏差分析

## 用户提示词

```text
请按成本管理工作流分析我上传的目标成本、合同台账、变更签证台账和动态成本月报。
项目在苏州，建筑面积 30,000 m²，数据日期 2026-09-30。
请输出动态成本计算、目标偏差、风险排序和管理层摘要。
未确认变更和风险预留要单列，不要把动态成本写成结算成本。
```

## 模拟数据

| 成本口径 | 金额（元） | 说明 |
|---|---:|---|
| 目标成本 | 90,000,000 | 已审批，3,000 元/m² |
| 已签合同 | 88,000,000 | 合同台账 |
| 待签合同预测 | 1,000,000 | 合约规划 |
| 已确认变更签证 | 1,500,000 | 已签认 |
| 已发生未确认变更 | 2,000,000 | 其中 1,200,000 元无书面指令 |
| 风险预留 | 1,000,000 | 待确认依据 |
| 可确认节余 | 500,000 | 已审批 |
| 结算成本 | 未定案 | 不能写成结算成本 |

## 示例计算

```text
动态成本 = 88,000,000 + 1,000,000 + 1,500,000 + 2,000,000 + 1,000,000 - 500,000
         = 93,000,000 元

目标偏差 = 93,000,000 - 90,000,000 = +3,000,000 元
偏差比例 = 3,000,000 / 90,000,000 = 3.33%
动态单方 = 93,000,000 / 30,000 = 3,100 元/m²
```

## 期望输出结构

1. 成本口径和数据日期汇总
2. 动态成本计算表（确定/预计/风险分列）
3. 目标偏差、合同偏差、变更偏差和指标偏差
4. 风险排序与管理层摘要
5. 需补资料清单
6. 质检摘要

## 验收要点

- 未确认变更 2,000,000 元和风险预留 1,000,000 元不得写成已确认成本。
- 1,200,000 元无书面指令的变更必须标记为“证据链不足/待补”。
- 结算成本未定案时，只能输出动态成本和目标偏差，不能输出最终成本。
- 管理层摘要必须包含风险排序、金额影响、建议动作、责任人和需要决策的事项。
- 所有金额标明数据日期、含税/不含税口径和依据来源。
