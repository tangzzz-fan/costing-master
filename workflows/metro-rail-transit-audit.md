# 地铁/轨道交通车站与盾构审核 Agent 工作流

## 适用用户

轨道交通造价人员、地铁项目商务/成本人员、造价咨询审核人员、项目经理。

## 输入文件

- 标段/工区划分、车站和区间清单、设计图纸、地质资料。
- 合同、招标文件、措施项目范围、交通导改和管线迁改界面。
- 项目所在地城市轨道交通计价表/消耗量、费用文件和信息价。
- 变更签证、索赔、监测方案、穿越审批、施工记录和影像。
- 进度款、结算书、付款台账和质保金台账。

## 模式判断

| 任务模式 | 重点 | 主要输出 |
|---|---|---|
| 清单/预算审核 | 车站、盾构、附属结构特征，工程量和单价 | 清单特征检查表、漏项登记、量价交叉验证 |
| 变更/索赔审核 | 地质、孤石、穿越、交通导改、管线迁改、监测 | 变更索赔证据清单、审核意见、需补资料 |
| 进度款审核 | 车站/区间计量、预付款、质保金、扣回 | 进度款审核表、问题台账 |
| 结算审核 | 合同内外界面、变更、调差、索赔、付款扣回 | 结算审核报告、审减/审增台账、管理层摘要 |

## 执行步骤

1. 确认项目所在地、适用标准、合同类型、标段/工区、车站/区间范围和地区计价依据。
2. 按 `input-specs/metro-boq.md` 读取清单，分开车站主体、附属结构、盾构区间、联络通道和临时工程。
3. 按 `references/metro-rail-transit.md` 和 `templates/metro-boq-feature-check-table.md` 检查车站/盾构清单特征，列出缺失、疑似漏项和需补资料。
4. 检查工程量与单价：核对设计图纸、工程量计算标准、当地地铁计价依据和信息价；只做 sanity check，不凭空算量。
5. 审核变更/索赔：按 `templates/metro-claim-evidence-checklist.md` 检查地质、孤石、穿越、交通导改、管线迁改和监测证据；证据不足的列为疑似/待补。
6. 审核材料调差：钢筋、混凝土、管片、防水等按合同和当地信息价；合同未明确可调的材料不得自行调差。
7. 审核进度款/结算：按 `workflows/progress-payment-audit.md` 和 `workflows/settlement-audit.md` 的规则，核对车站/区间计量、预付款、质保金、变更、调差和索赔。
8. 输出清单特征表、变更索赔证据清单、进度款/结算成果、需补资料和管理层摘要。
9. 按 `workflows/second-pass-review.md` 质检，重点检查金额闭合、专业界面、地区依据和结论强度。

## 中间判断

- 车站、区间、附属结构是否混算；管片按环还是按米；地连墙按面积还是体积。
- 交通导改、管线迁改是否已包含在措施项目、暂列金额或合同包干范围。
- 地质条件变化、孤石、穿越既有线是否属于合同约定风险；是否有书面指令和时效证据。
- 监测项目、频率和报警值是否满足规范和合同；监测费用是否漏项。
- 盾构管片、防水、盾构耗材是否可调；调差依据是否充分。
- 进度款和结算是否扣除预付款、甲供材、质保金和其他扣款。
- 结论是否超出证据；是否把疑似问题写成确定审减或法律结论。

## 风险控制

- 不编造地铁工程量、定额编号、综合单价、地质条件或监测数据。
- 不使用房建单方指标替代地铁车站/盾构造价。
- 不把交通导改、管线迁改、监测等专业界面重复计取。
- 不把疑似变更/索赔写成确定审减或确定无效。
- 地区定额/消耗量、信息价和合同条款必须可追溯。
- 缺关键资料时只做初筛，输出需补资料和人工确认点。

## 人工确认点

- 车站/区间/附属结构界面和合同范围。
- 地质条件、穿越风险、交通导改和管线迁改责任。
- 当地城市轨道交通计价依据的版本和适用性。
- 变更/索赔证据链、时效和授权签署。
- 材料调差范围和价格来源。
- 重大审减/审增、付款扣回和最终结算结论。
