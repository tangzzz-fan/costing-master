# 测试用例：成本管理与偏差分析

## 数据来源

模拟/教学数据，待后续替换为真实公开或脱敏实际资料。

## 模拟输入

项目：苏州住宅，建筑面积 30,000 m²，数据日期 2026-09-30。

成本数据：

- 目标成本：90,000,000 元（3,000 元/m²，已审批）。
- 已签合同：88,000,000 元。
- 待签合同预测：1,000,000 元。
- 已确认变更签证：1,500,000 元。
- 已发生未确认变更：2,000,000 元，其中 1,200,000 元只有会议纪要，无发包人书面指令。
- 风险预留：1,000,000 元。
- 可确认节余：500,000 元（已审批）。
- 结算成本：未定案。

## 期望行为

- 动态成本 = 88,000,000 + 1,000,000 + 1,500,000 + 2,000,000 + 1,000,000 - 500,000 = 93,000,000 元。
- 目标偏差 = 93,000,000 - 90,000,000 = +3,000,000 元，偏差比例约 3.33%；动态单方约 3,100 元/m²。
- 把已确认、未确认、风险预留和可确认节余分列，不把未确认金额写成已确认。
- 将 1,200,000 元无书面指令的变更标记为“证据链不足/待补书面指令”，不直接计入确定成本。
- 说明结算成本未定案，不能把动态成本写成结算成本。
- 输出目标成本测算/校核表、成本偏差分析表、管理层摘要、需补资料清单和质检摘要。
- 所有金额标明数据日期和含税/不含税口径；偏差原因引用合同、变更签证或成本台账。

## 失败表现

- 把动态成本直接写成结算成本或最终成本。
- 把未确认变更或风险预留计入确定成本。
- 遗漏待签合同预测或可确认节余。
- 未指出 1,200,000 元变更缺少书面指令。
- 未说明数据日期、含税口径或目标成本版本。
- 凭空填写目标成本、风险预留或单方指标。
