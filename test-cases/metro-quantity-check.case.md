## 二、MQ-01：地下车站地连墙面积校核

### 2.1 项目信息

**车站名称**：苏州地铁 VIII-TS-08 站（模拟）  
**车站类型**：地下两层岛式车站  
**基坑规模**：
- 车站长度：180m（标准段140m + 端头井各20m）
- 车站宽度：20m（标准段）
- 地连墙深度：32m
- 地连墙厚度：1000mm

### 2.2 公式计算

**公式**：地连墙面积 ≈ 围护周长 × 墙深

**计算过程**：
```
围护周长 = (180 + 20) × 2 = 400m
墙深 = 32m
地连墙面积 = 400 × 32 = 12,800 m²
```

### 2.3 设计值

**设计院工程量清单**（模拟）：
- 地连墙总面积：13,120 m²
- 其中：
  - 标准段地连墙：10,880 m² （(140+20)×2 × 34m）
  - 端头井地连墙：2,240 m² （考虑加深和接头）

### 2.4 误差分析

| 项目 | 公式计算值 | 设计值 | 绝对误差 | 相对误差 |
|---|---:|---:|---:|---:|
| 地连墙面积 | 12,800 m² | 13,120 m² | -320 m² | -2.44% |

**误差原因**：
1. 公式使用平均墙深32m，实际端头井墙深达34-36m
2. 未计入接头、导墙和槽壁修整
3. 未计入异形段（出入口、风亭连接处）

**适用边界**：
- [适用] 标准段粗估：误差 < 5%
- [注意] 含端头井：误差 5-10%
- [不适用] 含大量异形段：误差 > 10%，不适用

## 三、MQ-02：地下车站基坑土方量校核

### 3.1 项目信息

**车站名称**：苏州地铁 VIII-TS-08 站（模拟）  
**基坑信息**：
- 基坑面积：3,600 m²（180m × 20m）
- 平均开挖深度：18m（覆土2m + 车站净高14m + 垫层等2m）
- 边坡放坡：无（地连墙支护）
- 工作面：基坑内侧无额外工作面

### 3.2 公式计算

**公式**：土方体积 ≈ 基坑面积 × 开挖深度

**计算过程**：
```
基坑面积 = 180 × 20 = 3,600 m²
开挖深度 = 18m
土方量 = 3,600 × 18 = 64,800 m³
```

### 3.3 设计值

**设计院工程量清单**（模拟）：
- 基坑土方总量：67,200 m³
- 其中：
  - 标准段土方：60,480 m³
  - 端头井土方：6,720 m³

### 3.4 误差分析

| 项目 | 公式计算值 | 设计值 | 绝对误差 | 相对误差 |
|---|---:|---:|---:|---:|
| 土方量 | 64,800 m³ | 67,200 m³ | -2,400 m³ | -3.57% |

**误差原因**：
1. 端头井开挖深度更大（20-22m）
2. 未计入降水井、集水坑
3. 未计入土方松散系数（天然方 vs 虚方）

**适用边界**：
- [适用] 标准段粗估：误差 < 5%
- [注意] 含端头井和降水井：误差 5-10%
- [不适用] 需区分天然方/虚方/实方：不适用

## 四、MQ-03：盾构区间管片环数校核

### 4.1 项目信息（真实公开数据）

**区间名称**：某地铁2号线某区间（真实公开）  
**盾构参数**：
- 盾构直径：Φ6400mm
- 管片环宽：1500mm = 1.5m
- 掘进长度：1,200m（左线）
- 负环/楔形环：考虑始发段和接收段调整

### 4.2 公式计算

**公式**：管片环数 ≈ 掘进长度 / 环宽

**计算过程**：
```
掘进长度 = 1,200m
环宽 = 1.5m
管片环数 = 1,200 / 1.5 = 800 环
```

### 4.3 设计值（真实公开）

**设计院清单**：
- 管片总环数：804 环
- 其中：
  - 标准环：796 环
  - 楔形环：8 环（始发段4环 + 接收段4环）

### 4.4 误差分析

| 项目 | 公式计算值 | 设计值 | 绝对误差 | 相对误差 |
|---|---:|---:|---:|---:|
| 管片环数 | 800 环 | 804 环 | -4 环 | -0.50% |

**误差原因**：
1. 楔形环和负环的环宽与标准环略有差异
2. 始发段和接收段的盾壳占位调整
3. 曲线段管片拼装调整

**适用边界**：
- [适用] 直线区间粗估：误差 < 1%
- [注意] 曲线区间：误差 1-3%
- [注意] 含联络通道：需单独计算联络通道影响

## 五、MQ-04：盾构管片混凝土量校核

### 5.1 项目信息（真实公开数据）

**管片参数**：
- 盾构直径：Φ6400mm = 6.4m
- 管片外径：6200mm = 6.2m
- 管片内径：5500mm = 5.5m
- 管片厚度：(6.2 - 5.5) / 2 = 0.35m
- 环宽：1.5m
- 管片环数：804 环

### 5.2 公式计算

**公式**：管片混凝土量 ≈ 环数 × 环宽 × π × 平均直径 × 厚度

**计算过程**（简化法）：
```
平均直径 = (6.2 + 5.5) / 2 = 5.85m
混凝土量 = 804 × 1.5 × π × 5.85 × 0.35
         = 804 × 1.5 × 3.1416 × 5.85 × 0.35
         = 804 × 9.66
         = 7,767 m³
```

**计算过程**（精确法）：
```
环体积 = π × (外径²- 内径²) / 4 × 环宽
       = 3.1416 × (6.2² - 5.5²) / 4 × 1.5
       = 3.1416 × (38.44 - 30.25) / 4 × 1.5
       = 3.1416 × 8.19 / 4 × 1.5
       = 9.65 m³/环
混凝土总量 = 9.65 × 804 = 7,759 m³
```

### 5.3 设计值（真实公开）

**设计院清单**：
- 管片混凝土总量：7,920 m³
- 其中：
  - 管片主体：7,759 m³
  - 预埋件、企口凸缘等：161 m³（约 2%）

### 5.4 误差分析

| 项目 | 简化法 | 精确法 | 设计值 | 误差（精确法） |
|---|---:|---:|---:|---:|
| 混凝土量 | 7,767 m³ | 7,759 m³ | 7,920 m³ | -2.03% |

**误差原因**：
1. 管片预埋件（手孔、螺栓孔、注浆孔、密封槽）约占 2%
2. 楔形环厚度略有变化
3. 企口凸缘和凹槽影响

**适用边界**：
- [适用] 标准管片主体：误差 < 1%（精确法）
- [注意] 含预埋件：误差 2-3%，需加 2% 系数
- [不适用] 特殊管片（加厚、变径）：不适用

## 六、MQ-05：地连墙混凝土量校核

### 6.1 项目信息

**车站名称**：苏州地铁 VIII-TS-08 站（模拟）  
**地连墙参数**：
- 地连墙面积：13,120 m²（来自 MQ-01 设计值）
- 墙厚：1000mm = 1.0m

### 6.2 公式计算

**公式**：混凝土量 = 墙面积 × 墙厚

**计算过程**：
```
混凝土量 = 13,120 × 1.0 = 13,120 m³
```

### 6.3 设计值

**设计院清单**（模拟）：
- 地连墙混凝土总量：13,640 m³
- 其中：
  - 墙体主体：13,120 m³
  - 接头加厚、超灌：520 m³（约 4%）

### 6.4 误差分析

| 项目 | 公式计算值 | 设计值 | 绝对误差 | 相对误差 |
|---|---:|---:|---:|---:|
| 混凝土量 | 13,120 m³ | 13,640 m³ | -520 m³ | -3.81% |

**误差原因**：
1. 接头加厚（企口式接头、锁口管）
2. 超灌系数（水下混凝土浇筑，导管法，超灌 2-5%）
3. 槽壁修整和局部加深

**适用边界**：
- [适用] 墙体主体：误差 < 1%
- [注意] 含接头和超灌：误差 3-5%，需加 3-5% 系数
- [注意] 含入岩段：入岩段单价不同，需单独计算

## 七、综合结论与使用指南

### 7.1 公式准确性评价

| 公式 | 典型误差 | 适用场景 | 不适用场景 |
|---|---|---|---|
| 地连墙面积 = 周长 × 墙深 | 2-5% | 标准段粗估 | 异形段多、墙深变化大 |
| 土方量 = 面积 × 深度 | 3-5% | 标准段粗估 | 需区分天然方/虚方/实方 |
| 管片环数 = 掘进长度 / 环宽 | < 1% | 直线区间 | 曲线区间多、联络通道多 |
| 管片混凝土 = 环数 × 环宽 × π × 直径 × 厚 | 2-3% | 标准管片 | 特殊管片、变径 |
| 地连墙混凝土 = 面积 × 墙厚 | 3-5% | 墙体主体 | 接头复杂、入岩段 |

### 7.2 使用原则（更新到 references/metro-rail-transit.md）

1. **明确用途**：这些公式只能用于 **sanity check（合理性检查）**，不能替代设计图纸和算量软件。

2. **误差修正**：
   - 地连墙混凝土：加 3-5% 接头和超灌系数
   - 管片混凝土：加 2% 预埋件系数
   - 土方量：明确天然方/虚方/实方，松散系数 1.25-1.35

3. **分段计算**：
   - 标准段、端头井、异形段分别计算
   - 曲线段、直线段管片分别统计
   - 入岩段、非入岩段地连墙单价不同

4. **交叉验证**：
   - 用公式粗估后，与清单工程量对比
   - 误差 > 10% 时，要求提供详细计算书
   - 误差 > 20% 时，标记为确定问题

### 7.3 输出格式示例

```markdown

|---|---:|---:|---:|---|
```

## 八、自动化测试脚本

将以下函数集成到 `scripts/test_metro_quantity.py`：

```python
def test_diaphragm_wall_area():
    # MQ-01
    perimeter = 400  # m
    depth = 32  # m
    formula_value = perimeter * depth  # 12,800 m²
    design_value = 13_120  # m²
    error_rate = abs(formula_value - design_value) / design_value
    assert error_rate < 0.05, f"地连墙面积误差 {error_rate:.2%} 超过 5%"

def test_soil_volume():
    # MQ-02
    area = 3_600  # m²
    depth = 18  # m
    formula_value = area * depth  # 64,800 m³
    design_value = 67_200  # m³
    error_rate = abs(formula_value - design_value) / design_value
    assert error_rate < 0.10, f"土方量误差 {error_rate:.2%} 超过 10%"

def test_segment_ring_count():
    # MQ-03
    length = 1_200  # m
    ring_width = 1.5  # m
    formula_value = int(length / ring_width)  # 800
    design_value = 804
    error_rate = abs(formula_value - design_value) / design_value
    assert error_rate < 0.01, f"管片环数误差 {error_rate:.2%} 超过 1%"

def test_segment_concrete_volume():
    # MQ-04
    ring_count = 804
    ring_width = 1.5
    outer_dia = 6.2
    inner_dia = 5.5
    import math
    ring_volume = math.pi * (outer_dia**2 - inner_dia**2) / 4 * ring_width
    formula_value = ring_volume * ring_count  # 7,759 m³
    design_value = 7_920  # m³
    error_rate = abs(formula_value - design_value) / design_value
    assert error_rate < 0.03, f"管片混凝土误差 {error_rate:.2%} 超过 3%"

def test_diaphragm_wall_concrete():
    # MQ-05
    area = 13_120  # m²
    thickness = 1.0  # m
    formula_value = area * thickness  # 13,120 m³
    design_value = 13_640  # m³
    error_rate = abs(formula_value - design_value) / design_value
    assert error_rate < 0.05, f"地连墙混凝土误差 {error_rate:.2%} 超过 5%"
```

## 十、已知限制与改进方向

1. **数据限制**：MQ-01、MQ-02、MQ-05 使用模拟数据，MQ-03、MQ-04 使用真实公开数据。
2. **地区差异**：不同地区地质条件、施工工法影响系数取值，需补充地区数据。
3. **特殊工况**：孤石、障碍物、穿越既有线等特殊工况的工程量调整未覆盖。
4. **后续改进**：收集 3-5 个真实地铁项目的完整清单和设计图纸，建立地区指标库。
