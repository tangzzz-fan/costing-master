## 失败表现

### 已知失败场景

本测试用例设计时已覆盖所有已知失败场景，当前通过率100%。

### 潜在失败场景

1. **地方规则更新**
   - 症状：某地区执行时间变化，测试失败
   - 原因：地方文件更新，但测试用例未同步
   - 处理：更新 `REGIONAL_CONFIG` 中的执行时间

2. **新地区支持**
   - 症状：输入非江浙沪地区，返回"未知"
   - 原因：`REGIONAL_CONFIG` 未包含该地区
   - 处理：补充该地区配置

3. **国家标准变更**
   - 症状：国家标准发布日期错误
   - 原因：GB/T 50500-2024 发布日期存在争议
   - 处理：核实住建部公告，更新日期

### 失败时的输出示例

```
[失败] PA-01 苏州某商业综合体
  地区：江苏/苏州
  日期：2026-05-15 (招标公告)
  国家标准：GB/T 50500-2024 [预期: GB 50500-2013]
  地方规则：L00
  判断依据：2026-06-01前已发布招标公告或已签订合同的项目，按原规定执行

FAILED: 1 assertion(s) failed
```

### 故障排查步骤

1. 检查 `REGIONAL_CONFIG` 配置是否正确
2. 核对地方文件原文，确认执行时间
3. 检查判断逻辑（先判断地方，再确定国家标准）
4. 运行单个场景调试：
   ```python
   result = determine_applicable_standard("江苏/苏州", "2026-05-15", "招标公告")
   print(result)
   ```
