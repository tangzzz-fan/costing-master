# 测试用例：苏州地铁车站土建施工结算审核

## 场景

以苏州市轨道交通8号线工程土建施工项目（第三批）VIII-TS-08标为真实项目框架：

- 招标人：苏州市轨道交通集团有限公司。
- 中标人：中铁十局集团有限公司。
- 合同金额：934,771,363.61 元；合同工期 1507 天。
- 工程范围：时代广场站、右岸街站 2 座地下车站；3 个盾构区间。
- 公开来源：[苏州市公共资源交易平台](https://ggzy.suzhou.gov.cn/jyxx/003001/003001031/20260129/f8e70ee1-5c67-482a-997c-7e9c289e1e26.html)。

> 公开信息只用于提供真实项目框架。合同条款、清单、变更签证、材料价格、进度款和结算数据均为模拟，仅用于测试，不代表项目实际情况。

## 期望行为

- 按 `workflows/settlement-audit.md` 主流程审核，并调用变更签证、材料调差和进度款审核规则。
- 先输出《需补资料清单》，至少包括：合同专用条款、完整清单、变更签证原件、苏州市工程造价信息、管片/防水合同依据、索赔计算书、付款台账、质保金台账、竣工验收资料。
- 进度款复核：本期可计入已完产值 78,000,000 元，80% 为 62,400,000 元；预付款扣回 12,480,000 元；质保金 1,872,000 元；建议支付 48,048,000 元；未确认签证 2,000,000 元不计入确定应付。
- 结算审核：指出报审总额与组成合计存在 25,228,636.39 元未说明差异；V-003 交通导改疑似重复；V-004 管线迁改缺书面指令和时效；材料调差 20,000,000 元中当前有依据的仅约 2,370,000 元；索赔 10,000,000 元缺工期和费用证据；质保金未列明。
- 将确定问题、疑似问题、待补资料和人工确认分列，不直接给出最终审定价。
- 指出地铁车站/盾构清单特征（地连墙、盾构掘进、管片等）不完整，可能影响综合单价；同时说明当前 Skill 缺少地铁专项清单规则，需要补充。
- 输出结算审核报告、审减/审增问题台账、管理层摘要和质检摘要；所有问题引用文件名、页码/行号或条款号。

## 失败表现

- 直接接受报审结算价 1,050,000,000 元或给出最终审定价。
- 未核对合同和证据就把 V-003/V-004 写成确定审减或确定无效。
- 把材料调差 20,000,000 元全额确认，不使用苏州市工程造价信息或有依据的 2,370,000 元。
- 忽略 25,228,636.39 元未说明差异、索赔证据或质保金扣回。
- 使用全国指标或内置参考价替代项目所在地信息价。
- 未识别地铁车站/盾构清单特征缺口，也未说明缺少地铁专项规则。
