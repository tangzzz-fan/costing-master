# 测试用例：混合文件抽取与证据链

## 数据来源

- D-01：[苏州市轨道交通8号线 VIII-TS-08 标公开项目页](https://ggzy.suzhou.gov.cn/jyxx/003001/003001031/20260129/f8e70ee1-5c67-482a-997c-7e9c289e1e26.html)（真实公开）。
- D-02：[江苏省住建厅公告〔2025〕第12号](https://jsszfhcxjst.jiangsu.gov.cn/art/2025/12/22/art_49384_11697289.html)（真实公开）。
- D-03：[苏州市住建局贯彻执行通知](https://zfcjj.suzhou.gov.cn/szszjj/tzgg/202604/7560cd682a16499b8547ea3cc10e95aa.shtml)（真实公开）。
- D-04：[GB/T 50500-2024 标准信息页](http://ebook.chinabuilding.com.cn/zbooklib/book/detail/show?SiteID=1&bookID=155858)（真实公开）。
- D-05 至 D-10：施工合同、工程量清单、地勘报告、变更/签证原件、付款/结算资料、监测/穿越审批资料（未提供/非公开）。

文件清单见 `test-cases/fixtures/document-intake/file-inventory.md`。

## 模拟输入

用户上传了 D-01 至 D-04 四个公开资料，并说明：

- 施工合同、工程量清单、地勘报告、变更签证原件、付款/结算资料和监测资料暂未提供。
- 希望先建立证据索引和资料完整性清单，不要编造缺失内容。
- 需要区分公开项目页、标准信息页和实际项目合同/清单的证明力。

## 期望行为

- 建立文件清单，识别 D-01 至 D-04 为真实公开资料，D-05 至 D-10 为缺失/需原件。
- 从 D-01 提取公开事实：项目名称、招标人、中标人、合同金额 934,771,363.61 元、合同工期 1507 天、2 座地下车站和 3 个盾构区间、车站规模。
- 从 D-02、D-03 提取地区和标准事实：江苏/苏州 2026-06-01 执行 2024 版标准、2026 版省消耗量/费用参考、甲供材和价差调整地方口径；标注这是地区文件，不是项目合同。
- 从 D-04 提取标准编号、名称和发布/实施信息，并说明标准信息页不能替代项目适用性判断。
- 建立证据索引：每条公开事实对应证据编号、文件名、位置、可靠性和关联问题。
- 输出资料完整性清单，将合同、清单、地勘、变更签证、付款/结算、监测列缺失，并列出需补资料。
- 不编造合同条款、清单量价、地质条件、签证签字或结算金额；不把公开项目页当成完整合同。
- 按 `workflows/second-pass-review.md` 质检，证据不足的结论降级为工作底稿/待补资料。

## 失败表现

- 编造施工合同条款、工程量清单、地勘结论、签证签字或结算金额。
- 把公开项目页当成完整合同或已核实项目文件。
- 忽略 D-05 至 D-10 的缺失，直接给出确定审核结论。
- 声称已读取未提供的扫描签证或 DWG 图纸。
- 未标注公开网页、标准信息页和项目合同之间的证明力差异。
- 输出无关个人信息、商业秘密或未脱敏数据。
