# 测试用例：Excel 输出实践

## 数据来源

真实公开项目框架 + 现有测试证据：苏州地铁 VIII-TS-08 公开项目页、江苏省住建厅公告、苏州市住建局通知，以及现有苏州地铁结算场景。成本细节为模拟，仅用于 Excel 输出结构测试，不代表项目实际结算。

- [苏州市公共资源交易平台 VIII-TS-08 标](https://ggzy.suzhou.gov.cn/jyxx/003001/003001031/20260129/f8e70ee1-5c67-482a-997c-7e9c289e1e26.html)
- [江苏省住建厅公告〔2025〕第12号](https://jsszfhcxjst.jiangsu.gov.cn/art/2025/12/22/art_49384_11697289.html)
- [苏州市住建局贯彻执行通知](https://zfcjj.suzhou.gov.cn/szszjj/tzgg/202604/7560cd682a16499b8547ea3cc10e95aa.shtml)

## 场景

用户要求把苏州地铁 VIII-TS-08 的结算审核、进度款、材料调差和证据索引整理成 Excel 工作簿，供内部审核使用。

- 输出对象：项目成本负责人和审核人。
- 交付状态：内部送审稿，不对外交付。
- 需要包含：封面与版本、数据源与口径、原始数据、计算明细、汇总、问题台账、证据索引、需补资料、质检与审核。
- 使用 `templates/excel/` 下的 CSV 模板。

## 期望行为

- 识别适合 Excel 的高频输出：清单特征、综合单价、投标报价、材料调差、进度款、结算台账、成本偏差、证据索引。
- 工作簿按 `references/excel-output-guide.md` 的 00-08 sheet 结构组织，原始数据表不合并单元格。
- 使用公式而非硬编码：合价=工程量×综合单价；调差=数量×(施工价−基准价×(1±风险幅度))；进度款=已完产值×比例−扣回−质保金。
- 判断等级统一为“确定/疑似/待补/人工确认”，状态统一为“待处理/处理中/已关闭”。
- 关键结论有证据编号；证据索引包含文件名、页码/行号/工作表、可靠性。
- 封面记录项目、任务、版本、日期、适用标准、地方规则、编制/审核人。
- 交付前导出 PDF/Word 并完成人工审核和签认；Excel 只作为计算和跟踪底稿。
- AI 不签认、不盖章、不代替注册造价工程师。

## 失败表现

- 所有内容堆在一张 sheet，原始数据和计算混在一起。
- 合计、合价、调差、进度款用手工数字，没有公式或计算依据。
- 没有证据编号、证据索引或数据来源。
- 原始数据表使用合并单元格，无法筛选和计算。
- 缺少版本、日期、适用标准、地方规则或编制/审核人。
- 把 Excel 工作底稿当作最终签章文件，或把 AI 写成签认人。
- 把模拟数据当作项目实际数据。
