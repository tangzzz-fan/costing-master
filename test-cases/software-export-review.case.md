# 测试用例：软件导出清单体检与问题回填

## 数据来源

- 真实公开清单：江苏政府采购网《2025 年城市安全建设-市管 12 座桥梁轻量化监测设备安装》（项目编号 JSZC-320300-ZCGL-G2025-0016）汉桥分部分项工程和单价措施项目清单与计价表摘录，来源 [江苏政府采购网](http://www.ccgp-jiangsu.gov.cn/fileApi/320000/d42fe73c23b8489eb3d0e535eb875c7b.pdf)，PDF 第 1-3 页，2026-10-31 下载并核对。
- 真实公开标准：江苏省《建设工程电子招标投标造价数据交换标准》，[江苏省建设工程招标网](http://jszb.com.cn/JSZB/UploadFile/20260414092904254.pdf)，2026-06-01 起执行，用于核对精度、一致性校验和计算规则。
- 问题样例：在汉桥真实清单基础上改造的 `hanqiao-export-issues.csv`，仅用于验证检查规则，不是项目实际数据。
- 导出格式：按计价软件常见表头构造的 CSV 和 XLSX；真实项目导出文件未公开，标记为“需项目原件”。
- 来源、哈希、抽取和改造说明见 `test-cases/fixtures/software-export/provenance.md`。
- 测试参数说明：命令中的 `--standard 2024` 仅用于验证 2024 版检查规则，不代表该公开项目实际适用标准；实际项目应按招标公告/合同签订日期、地方执行时间和合同约定判断标准版本。

## 期望行为

### 一、真实清单体检

执行：

```bash
python3 scripts/check_software_export.py \
  test-cases/fixtures/software-export/hanqiao-real-boq.csv \
  --standard 2024 --out 问题回填.csv --md 体检报告.md
```

期望：

- 自动跳过前 5 行标题/说明/空行，识别表头在第 6 行。
- 识别 21 个清单项、4 个分部/章节行、2 个合计行。
- 明细合价合计 216,994.83 元，合计行 216,994.84 元，差额 0.01 元在容差内。
- 不产生“确定问题”错误。
- 对 RVV 电缆、采集软件、传输软件、数据平台对接、软硬件调试费、特种设备租赁、交通组织、4G 网络通讯等 8 个项目特征为空，输出“待补资料”警告。
- 对靶标、板卡、电力电缆、镀锌钢管等显示单价与合价存在四舍五入差异的项目，输出“人工确认”提示，不直接认定为算术错误。
- 分部行（D.3.9 汉桥、系统硬件费用、系统软件费用、系统集成与调试）和合计行不计入清单项，也不误报编码缺失。
- 问题回填 CSV 使用 UTF-8 BOM，表头与 `templates/software-issue-return-list.md` 一致，包含工作表、行号、清单编码、原值、问题类型、判断等级和回填状态。
- Markdown 报告包含工作表汇总、问题清单和边界说明。

### 二、问题样例体检

执行：

```bash
python3 scripts/check_software_export.py \
  test-cases/fixtures/software-export/hanqiao-export-issues.csv --standard 2024
```

期望识别并分类：

- 清单编码重复（确定问题）。
- 合价不等于工程量×综合单价（确定问题）。
- 工程量为负数（确定问题）。
- 清单行缺项目编码（待补资料）。
- 综合单价为 0（人工确认）。
- 同名、同特征、同单位重复列项（疑似问题）。
- 11 位编码疑似丢前导零（人工确认），且不因补零后与已有编码相同而误报重复。
- 2024 版项目出现“规费”独立费用行（疑似问题/人工确认）。
- 合计行与清单项汇总不一致（确定问题）。
- 名称提示单位与导出单位疑似不匹配（疑似问题）。
- 退出码为 1，问题回填 CSV 包含至少 5 条错误。

### 三、格式和边界

- XLSX（含共享字符串）读取结果与 CSV 一致，工作表名保留。
- GB18030/GBK 编码的 CSV 可读取。
- `.24jz` 等专有文件返回退出码 2，并提示改用 Excel/CSV；不尝试解析或修改源文件。
- `--template` 输出规范表头、别名和问题回填表头。
- 无输入时返回用法提示，退出码 2。

### 四、工作流和回填

- 工作流明确“导出→体检→回填→复检”闭环，问题按单位工程、工作表、软件行号和清单编码回填。
- 明确不直接修改招标人提供的清单项、暂列金额、暂估价、税率和安全生产费率。
- 明确自动体检不替代软件校验、交易平台 XSD 校验、清标工具、评标委员会和注册造价工程师判断。
- 明确未公开招标文件、控制价和投标报价的保密要求。

## 失败表现

- 把标题行或分部行识别为清单项，导致清单项数量、合价或编码检查误报。
- 把显示单价四舍五入差异直接写成“确定问题”或审减结论。
- 把项目特征为空、单位异常、同名重复项直接写成违法、废标或低于成本结论。
- 自动修改源文件、直接编辑导出的 Excel 或声称可以回写 `.GBQ/.GCCP/.24jz`。
- 不核对合计行、漏掉负数、零单价、重复编码或 2024 版规费问题。
- 问题回填清单缺少工作表、行号或清单编码，无法在软件中定位。
- 未说明地区、标准版本、软件版本或导出时间，直接用默认值补全。
- 把真实公开清单的金额、编码或项目特征改写后当作项目事实。
- 声称通过体检即可保证平台接收、投标有效或清标通过。
