# 标准文本验证测试用例

> 测试目标：验证 `references/standards-index.md` 中登记的标准编号、名称、发布/实施日期和官方来源的准确性。  
> 数据来源：中国建筑出版在线、住建部官网、国家标准公告、地方住建厅通知。  
> 关联规则：R-008（标准变动检查）、R-009（地区资料核对）。  
> 测试方法：人工核对标准原文，填写验证记录表。

### 5.2 更新 standards-index.md 的步骤

1. 根据验证结果，更新表格中的"发布/实施"列
2. 更新"官方来源"列的链接（确保可访问）
3. 更新"最近核对"列为实际验证日期
4. 更新"审核状态"列为"已人工审核 YYYY-MM-DD"
5. 在"变更记录"章节新增一行
6. 同步更新机器可读 JSON 的日期字段
7. 运行 `python3 scripts/validate.py` 检查链接
8. 提交前由审核人签名确认

## 失败表现

### 典型失败场景

1. **发布日期不一致**
   - 症状：文档标注日期与官方公告不符
   - 示例：GB/T 50500-2024 发布日期 2024-11-26 vs 2024-12-30
   - 处理：以住建部公告或国家标准公告为准，更新文档

2. **官方链接失效**
   - 症状：点击链接404或网站改版
   - 处理：搜索新链接，或标注"链接失效 YYYY-MM-DD"，保存截图备份

3. **标准编号错误**
   - 症状：GB 50500-2013 误写为 GB/T 50500-2013
   - 处理：核对官方公告，修正标准编号（GB vs GB/T）

4. **地方文件日期矛盾**
   - 症状：江苏省住建厅公告〔2025〕第12号日期标注为2025-12-22（未来日期）
   - 处理：核实原文，可能是2024-12-22笔误

5. **轨道交通专篇不明确**
   - 症状：2026版江苏省消耗量是否含轨道交通专篇，公开文件未明确
   - 处理：联系江苏省造价总站确认，或标注"待官方明确"

### 故障排查步骤

1. **链接失效**
   - 检查网站是否改版（如住建部官网改版）
   - 搜索标准编号或文件文号
   - 联系官方或造价协会

2. **日期矛盾**
   - 优先以盖章公告原文为准
   - 核对发布公告编号
   - 如有多个日期版本，标注来源

3. **标准缺失**
   - 联系中国建筑出版社或购买标准
   - 查询图书馆、单位订阅
   - 使用地方贯彻通知替代（次优）
