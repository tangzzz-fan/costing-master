# 标准文本验证测试用例

> 测试目标：验证 `references/standards-index.md` 中登记的标准编号、名称、发布/实施日期和官方来源的准确性。  
> 数据来源：中国建筑出版在线、住建部官网、国家标准公告、地方住建厅通知。  
> 关联规则：R-008（标准变动检查）、R-009（地区资料核对）。  
> 测试方法：人工核对标准原文，填写验证记录表。

### 5.2 更新 standards-index.md 的步骤

1. 根据验证结果，更新表格中的"发布/实施"列
2. 更新"官方来源"列的链接（确保可访问）
3. 更新"最近核对"列为实际验证日期
4. 更新"审核状态"列为"已人工审核 YYYY-MM-DD"
5. 在"变更记录"章节新增一行
6. 同步更新机器可读 JSON 的日期字段
7. 运行 `python3 scripts/validate.py` 检查链接
8. 提交前由审核人签名确认
