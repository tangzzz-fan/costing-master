# 模拟合同条款摘要

> 本文件是测试用模拟合同，不是 VIII-TS-08 标的实际合同原文。条款仅用于验证结算审核、进度款审核、变更签证和材料调差工作流。

## 一、合同基本信息

| 项目 | 内容 |
|---|---|
| 合同类型 | 单价合同 |
| 合同价 | 934,771,363.61 元 |
| 合同工期 | 1507 天 |
| 质量标准 | 合格 |
| 合同签订日期 | 2020-05-18（公开中标公示） |
| 计价标准 | GB 50500-2013 + 江苏省 2014 版计价依据（模拟约定） |
| 项目所在地 | 江苏省苏州市 |

## 二、付款与结算

- 进度款按当期已完合格工程量产值的 80% 支付。
- 质量保证金按当期应付款的 3% 扣留，总额不超过结算总额的 3%。
- 预付款为合同价的 10%，即 93,477,136.36 元；累计完成产值达到合同价 30% 后，按每期应付款的 20% 扣回。
- 竣工结算按合同约定的结算期审核；结算资料包括结算书、工程量计算书、变更签证、材料调差、索赔、付款和扣款资料。
- 结算审核以合同、经确认的工程量、变更签证、信息价和计算书为依据；证据不足的金额不得计入确定审定金额。

## 三、变更与签证

- 变更/签证应在事件发生后 14 天内书面申报，经发包人书面指令和监理签认。
- 变更计价顺序：合同已有适用单价 → 类似单价 → 新组价。
- 交通导改、管线迁改按合同措施项目、暂列金额或发包人指令处理；是否已包含在合同范围内，需核对合同清单和措施项目。
- 未经书面指令、超出时效或缺少数量/单价依据的签证，列为疑似或待补资料，不直接计入确定金额。

## 四、材料调差

- 钢筋、商品混凝土为可调材料；承包人承担基准价 ±5% 以内的风险，超出部分按合同约定调整。
- 基准期为 2020 年第 5 期苏州市工程造价信息（模拟）；施工期按材料进场月份加权平均。
- 调差只计取超出风险幅度的部分；价差调整只计增值税，不计管理费、利润和措施项目费（模拟地方口径）。
- 盾构管片、防水材料等未在合同中明确可调的，需按合同和补充协议确认，不得自行调差。

## 五、索赔与争议

- 索赔应有合同依据、事件事实、证据链和时效内的书面通知。
- 工期索赔需提供关键线路影响分析；费用索赔需提供计算书和凭证。
- 争议按合同约定的协商、调解、争议评审、仲裁或诉讼处理。
