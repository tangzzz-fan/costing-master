## 测试要求

- 从 D-01 至 D-04 提取公开事实，并在证据索引中记录文件名和位置。
- 将 D-05 至 D-10 列为缺失/需原件，不编造合同条款、清单量价、地质条件、签证签字或结算金额。
- 不把公开项目页当成完整合同，不把标准信息页当成项目适用性的最终结论。
- 输出证据索引、资料完整性清单、抽取摘要、需补资料和人工确认点。
