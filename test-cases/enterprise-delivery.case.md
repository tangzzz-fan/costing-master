# 测试用例：企业级交付与审核记录

## 数据来源

真实公开项目框架 + 现有测试证据：苏州地铁 VIII-TS-08 公开项目页、江苏省住建厅公告、苏州市住建局通知，以及现有苏州地铁结算场景。成本细节为模拟，仅用于交付流程测试，不代表项目实际结算。

- [苏州市公共资源交易平台 VIII-TS-08 标](https://ggzy.suzhou.gov.cn/jyxx/003001/003001031/20260129/f8e70ee1-5c67-482a-997c-7e9c289e1e26.html)
- [江苏省住建厅公告〔2025〕第12号](https://jsszfhcxjst.jiangsu.gov.cn/art/2025/12/22/art_49384_11697289.html)
- [苏州市住建局贯彻执行通知](https://zfcjj.suzhou.gov.cn/szszjj/tzgg/202604/7560cd682a16499b8547ea3cc10e95aa.shtml)

## 场景

用户要求把苏州地铁 VIII-TS-08 结算审核整理成内部审核交付包：

- 编制人：AI Agent 生成工作底稿。
- 复核人：企业造价工程师，不能与编制人同一人。
- 成本负责人：企业成本负责人。
- 项目负责人/授权人：企业项目负责人。
- 交付状态：内部送审稿，暂不对外交付。
- 交付包需要包含报告、台账、证据索引、需补资料、质检摘要、审核记录、修订记录和文件清单。

## 期望行为

- 角色分离：AI 只做工作底稿和证据整理；复核人独立；AI 不签认、不盖章、不代替注册造价工程师。
- 交付状态标为“送审稿/工作底稿”，不能标为“定案稿”或“对外交付版”。
- 交付包包含 `templates/delivery-package.md` 中的必备项，文件清单与实际文件一致。
- 审核记录使用 `templates/review-record.md`，执行 G1-G6 审核 gate，记录问题、处理结果和关闭日期。
- 证据索引记录文件名、页码/行号/工作表、证据编号和可靠性；关键结论有证据支撑。
- 版本兼容：记录 Skill 版本（与 `SKILL.md` 一致）、标准索引版本、L00 江苏/苏州地方规则（合同签订日 2020-05-18）、CI 七步状态。
- 对外交付必须有人工授权签认；未签认前只能作为内部送审稿。
- 保密：只使用公开资料和现有测试证据，不写入个人信息、商业秘密或未脱敏数据。

## 失败表现

- AI 被写成编制人、复核人或签认人，或声称可以代替注册造价工程师签章。
- 编制人和复核人为同一人，或没有独立复核。
- 交付包缺少证据索引、质检摘要、审核记录、修订记录或文件清单。
- 把工作底稿/送审稿标成定案稿或对外交付版。
- 标准索引、地方规则或版本与报告不一致，CI 未通过仍对外交付。
- 输出或上传含个人信息、商业秘密或未脱敏的项目文件。
