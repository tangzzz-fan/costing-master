| 检查项 | 结果 | 说明 |
|---|---|---|
| 同类项单价离散度（CV） |  | CV > 30% 标注疑似套项错误或特征差异未体现 |
| 钢筋/混凝土/模板含量 |  | 偏离参考区间时注明结构形式、地下室占比和建筑面积口径 |
| TOP20 金额占比 |  | 宜 > 50% 且 < 85% |
| 单项金额占比 |  | > 20% 重点核实工程量和单价 |
| 其他异常 |  |  |

## 填写要求

- 只指出特征问题，不直接生成新综合单价。
- “详见图纸”能否接受需结合招标文件和图纸完整性判断。
