# 造价谈判策略指南

> 适用对象：造价工程师、项目经理、商务负责人  
> 场景：合同谈判、变更谈判、结算谈判、争议调解  
> 原则：依据优先、证据充分、理性让步、双赢思维

## 一、谈判前准备

### 1.1 证据材料清单

#### 合同谈判阶段
- [ ] 招标文件完整版（含答疑纪要）
- [ ] 工程量清单及计价依据
- [ ] 施工图纸（含地勘报告）
- [ ] 类似项目合同条款对比
- [ ] 市场询价和信息价
- [ ] 风险识别清单

#### 变更谈判阶段
- [ ] 变更指令（书面、签字、授权）
- [ ] 设计变更图纸（加盖设计单位章）
- [ ] 现场签证单（三方签字）
- [ ] 照片、视频、监测数据
- [ ] 施工日志、工作联系单
- [ ] 综合单价分析（人材机分解）

#### 结算谈判阶段
- [ ] 合同及补充协议全套
- [ ] 竣工图纸和工程量复核
- [ ] 已确认变更签证汇总
- [ ] 材料调差计算书
- [ ] 审减问题逐项答辩稿
- [ ] 类似项目结算案例

### 1.2 依据优先级

**依据层级**（从高到低）：
1. **合同约定** - 最高优先级，白纸黑字
2. **国家标准** - GB/T 50500-2024、九本计算标准
3. **地方规定** - 江浙沪住建厅文件
4. **行业惯例** - 当地造价协会、类似项目做法
5. **市场询价** - 三家以上供应商报价

**谈判金句**：
- "合同第X条明确约定..."
- "根据GB/T 50500-2024第X.X.X条..."
- "江苏省住建厅公告〔2025〕第12号规定..."
- "苏州地铁X号线、Y号线同类项目均按此处理..."

### 1.3 底线与让步空间

| 谈判项 | 底线 | 让步空间 | 说明 |
|---|---|---|---|
| 工程量 | 竣工图纸核定量 | ±2%测量误差 | 超出部分要求提供计算书 |
| 综合单价 | 合同清单单价 | 按定额换算规则 | 人材机分项调整 |
| 材料调差 | 合同约定风险幅度 | 信息价与市场价差异 | 只调超出风险幅度部分 |
| 变更单价 | 类似清单项单价 | ±10% | 无类似项时市场询价 |
| 索赔工期 | 关键线路上的延误 | 非关键线路打折 | 需CPM网络图 |
| 索赔费用 | 实际发生损失 | 间接费用打折 | 需费用凭证 |

## 二、常见争议点与应对策略

### 2.1 材料调差争议

#### 争议点1：风险幅度理解不一致

**承包人主张**："材料涨价了，全额调差"

**发包人主张**："合同约定5%风险幅度，只调超出部分"

**应对策略**：
1. **依据**：翻开合同材料价格风险条款，逐字读给对方听
2. **计算**：当场演示风险幅度计算公式
   ```
   调差金额 = 工程量 × (施工期信息价 - 基准期信息价) × (1 - 风险幅度)
   ```
3. **类似项目**："苏州地铁X号线、Y号线都是这么处理的"
4. **让步空间**：如合同未明确，可协商风险幅度（通常5%或10%）

**谈判技巧**：
- 不要一开始就说"不同意"，先听对方完整诉求
- 用计算器当场算，让数字说话
- 提出"按合同来"时语气平和，不是拒绝而是执行规则

#### 争议点2：信息价来源和期别

**承包人主张**："用X月信息价"

**发包人主张**："按实际施工月信息价，但你这个月没施工"

**应对策略**：
1. **核对施工日志**：证明实际施工月份
2. **合同约定**：优先按合同约定的信息价期别（如"施工当月信息价"）
3. **无约定时惯例**：主材按采购月，人工按实际施工月
4. **让步方案**：如跨月施工，按加权平均

**谈判金句**：
- "施工日志显示，该工程量在X月完成，应采用X月信息价"
- "合同第X条约定'按施工当月信息价调整'"
- "如果跨两个月，我们可以按实际工程量比例加权平均"

#### 争议点3：江苏"只计增值税"规定

**承包人主张**："价差调整应含管理费、利润"

**发包人主张**："江苏规定只计增值税"

**应对策略**：
1. **出示文件**：打印江苏省住建厅公告〔2025〕第12号原文
2. **解释原因**："国家标准改革后，价差只调税金，防止重复计费"
3. **计算演示**：
   ```
   价差金额（含税）= 500,000元
   只计增值税 = 500,000 / 1.09 × 0.09 = 41,284元
   ```
4. **类似项目**："这是江苏省统一规定，所有项目都这么执行"

**让步空间**：
- 如果承包人坚持按全额调差，可建议通过补充协议明确
- 但需业主方同意，且要说明与地方规定不符

### 2.2 工程量争议

#### 争议点4：清单量与实际量不符

**承包人主张**："实际完成量比清单多，要按实结算"

**发包人主张**："清单量是固定的，多做是你的施工组织问题"

**应对策略**：
1. **区分清单特征**：
   - 固定总价项：按清单量结算，不调整
   - 估算工程量项：按实际完成量结算
   - 暂估价项：按实际确认量结算
2. **核对合同**：合同工程量调整条款怎么写
3. **现场核对**：竣工图纸 + 现场实测

**合理性判断**：
- 增加量 < 10%：施工正常损耗，不调整
- 增加量 10-20%：部分调整，需说明原因
- 增加量 > 20%：全部调整，但需变更指令

**谈判金句**：
- "合同清单说明第X条，该项为估算工程量，按实结算"
- "竣工图纸显示实际完成X单位，与清单量Y的差异在合理范围内"
- "增加的工程量是因为设计变更，有监理指令X号"

#### 争议点5：地铁工程量计算规则

**承包人主张**："地连墙按墙中心线计算"

**发包人主张**："按墙外边线计算"

**应对策略**：
1. **查清单特征描述**：清单项目特征怎么写的
2. **查计算标准**：GB/T 50861-2024城市轨道交通工程量计算标准
3. **查合同约定**：合同有无补充说明
4. **行业惯例**：苏州地铁通常按墙外边线计算

**让步方案**：
- 如合同未明确，按"有利于承包人"原则
- 或协商按实际混凝土量计算（最准确）

### 2.3 变更签证争议

#### 争议点6：口头指令是否有效

**承包人主张**："监理口头让我做的，应该算变更"

**发包人主张**："没有书面指令，不认可"

**应对策略**：
1. **合同条款**：变更必须有书面指令（几乎所有合同都这么写）
2. **证据补强**：
   - 施工日志有无记录
   - 监理例会纪要有无提及
   - 工作联系单、微信记录（辅助）
3. **协商路径**：
   - 请监理补签证（如确实发生）
   - 或按"情况说明"处理，打折结算
4. **预防措施**：今后必须先要书面指令再施工

**谈判金句**：
- "合同第X条明确要求变更必须有书面指令"
- "如果确实发生，请监理单位补充签证说明情况"
- "考虑到实际情况，我们可以协商一个折扣比例"

#### 争议点7：变更单价定价依据

**承包人主张**："按市场价定价"

**发包人主张**："按合同类似清单项单价"

**应对策略**：
1. **合同约定优先**：合同变更定价条款怎么写
2. **定价顺序**（国际惯例FIDIC）：
   - 有类似清单项 → 参照清单单价
   - 无类似项但有定额 → 按定额组价
   - 无定额 → 市场询价（三家以上）
3. **综合单价分析**：
   - 人工费、材料费、机械费逐项核对
   - 管理费、利润按合同费率
   - 措施费按实际发生

**谈判技巧**：
- 提前准备综合单价分析表
- 如对方提出的单价明显偏高，当场做人材机分解
- "这个单价包含哪些内容？我们逐项核对一下"

### 2.4 结算审减争议

#### 争议点8：审减比例过高

**承包人主张**："审减20%太多了，不合理"

**发包人主张**："这些都是有问题的，必须审减"

**应对策略**：
1. **逐项答辩**：不要笼统争论比例，而是逐项核对
2. **分类汇总**：
   - 确定错误（工程量算错、单价套错） → 必须调整
   - 理解分歧（计算规则不同） → 协商统一标准
   - 证据不足（签证不全） → 补充证据或打折
3. **合理性评估**：
   - 审减 < 5%：正常范围
   - 审减 5-10%：一般项目水平
   - 审减 > 15%：需说明原因（可能有虚报）

**谈判金句**：
- "我们逐项核对，确定错误的我们认可调整"
- "这个审减项，我们理解不同，能否听听我们的依据？"
- "审减20%意味着1亿多，能否给个详细清单？"

**让步策略**：
- 对确定错误的审减项，快速认可，建立信任
- 对有争议的项，提出详细依据和计算过程
- 最后留2-3个小额争议项作为"让步空间"

#### 争议点9：未确认变更的处理

**承包人主张**："已经施工完了，应该结算"

**发包人主张**："没确认单价，不能结算"

**应对策略**：
1. **确认已发生**：证据齐全（指令、照片、验收）
2. **单价协商**：
   - 按类似清单项单价
   - 或按定额暂定单价
   - 或打折结算（如80-90%）
3. **分阶段结算**：
   - 已确认的先付
   - 未确认的留5-10%质保金，待确认后支付
4. **争议解决条款**：合同约定的争议解决方式（协商/调解/仲裁）

**谈判金句**：
- "工程已实际完成，有监理指令和验收记录"
- "单价我们可以协商，建议按XX项类似单价暂定"
- "如果暂时无法确认，我们接受按90%暂付，确认后补齐"

## 三、谈判技巧与心理博弈

### 3.1 开局策略

**第一次报价**：
- 承包人：留20-30%谈判空间（但不能虚高到离谱）
- 发包人：按合理审减比例（5-10%），留10%让步空间

**第一轮回应**：
- 不要立即接受对方第一次报价
- 表达"需要内部研究"，争取时间
- 释放信号："这个价格/审减比例需要讨论"

### 3.2 中场策略

**分项击破**：
- 不要一次谈所有项，容易乱
- 先谈容易达成一致的项（建立信任）
- 再谈有分歧的项（逐项解决）
- 最后谈金额最大的项（留作主战场）

**信息不对称利用**：
- 承包人掌握：实际成本、施工难度、市场价
- 发包人掌握：审计标准、类似项目、预算控制线
- 双方都不要过早暴露底牌

**时间压力**：
- 承包人：资金压力大，希望快速结算
- 发包人：付款有流程，不急于一时
- 临近年底、季度末，承包人让步空间大

### 3.3 收尾策略

**最后让步**：
- 不要一次让到底，分2-3次让
- 每次让步要换取对方让步
- 最后1-2%留作"诚意让步"

**达成协议**：
- 口头达成后，当场确认要点
- 会后1-2天内发书面纪要（防止反悔）
- 纪要需双方签字确认

**不能达成时**：
- 启动合同争议解决条款（协商/调解/仲裁）
- 未达成一致的项单独列账，已达成的先执行
- 避免"一锤子买卖"，保持合作关系

### 3.4 话术模板

#### 开场白
> "感谢各位今天抽时间坐下来协商。我们的目标是在合同框架内，公平合理地解决分歧，希望大家坦诚交流。"

#### 表达坚持
> "这个问题合同第X条有明确约定，我们必须按合同执行。不是我们不想帮忙，是合同和审计都要求我们这么做。"

#### 表达理解
> "我理解贵方的困难/诉求，但我们也有预算/审计的压力。能不能找一个双方都能接受的方案？"

#### 提出方案
> "我们有个建议：对于XX项，按照XX依据，定价为XX。这个方案兼顾了合同约定和实际情况，您看如何？"

#### 请求让步
> "我们已经在XX项做了调整，是否贵方也能在YY项做些让步，这样我们才能达成一致。"

#### 拒绝不合理要求
> "这个要求超出了合同范围/市场行情，恕我们无法接受。不过我们可以在XX项上再讨论一下。"

#### 达成一致
> "好的，我确认一下：XX项按XX处理，YY项按YY处理，ZZ项我们会后再研究。大家对这个方案没有异议吧？"

## 四、典型案例示例

### 案例1：苏州地铁某站材料调差谈判

**背景**：
- 合同价5.2亿元，钢筋、商品混凝土价格上涨
- 承包人申报材料调差3,000万元
- 合同约定5%风险幅度，超出部分按信息价调整

**谈判过程**：

**第1回合**：
- 承包人："钢筋从4,200涨到4,800，商品混凝土从580涨到650，全额调差3,000万"
- 发包人："合同约定5%风险幅度，需扣除"
- **结果**：承包人同意按风险幅度计算，但主张按"含税全额"

**第2回合**：
- 承包人："3,000万已扣除5%风险幅度"
- 发包人："江苏规定价差调整只计增值税，应为270万"
- 承包人："合同签订时没这个规定"
- **僵持点**：江苏规定的适用性

**第3回合（核心博弈）**：
- 发包人：出示江苏省住建厅公告〔2025〕第12号原文
- 承包人：合同签订时（2025-05）该规定尚未发布（2024-12）
- **破局方案**：双方各让一步
  - 发包人：认可合同签订时无此规定，不溯及既往
  - 承包人：接受按"价差×50%"折中计算
  - **最终**：1,500万元

**经验总结**：
1. 地方新规与合同签订时点的冲突，按"不溯及既往"原则
2. 僵持时，双方各让一步（50%折中）是常见方案
3. 提前准备文件依据，但也要给对方台阶下

### 案例2：某地铁车站工程量审减答辩

**背景**：
- 结算申报1.2亿元
- 审计初审意见：审减2,400万元（20%）
- 主要审减项：地连墙面积、土方量、变更签证

**答辩策略**：

**第1步：分类整理审减项**

| 审减项 | 审减金额 | 承包人意见 | 处理方式 |
|---|---:|---|---|
| 地连墙面积多算300m² | 35万 | 认可 | 调整 |
| 土方量计算规则不同 | 240万 | 有争议 | 重点答辩 |
| 变更签证不全 | 500万 | 补充证据 | 补充后重审 |
| 清单单价套用错误 | 180万 | 认可 | 调整 |
| 材料调差虚高 | 1,200万 | 有争议 | 重点答辩 |
| 措施费重复计取 | 245万 | 认可 | 调整 |

**第2步：重点答辩项逐项准备**

**答辩项1：土方量计算规则**
- 审减依据：按天然方计算，承包人按虚方
- 承包人答辩：清单特征注明"按虚方"，且已确认
- 证据：清单项目特征表、答疑纪要
- **结果**：审计认可，不审减

**答辩项2：材料调差**
- 审减依据：按江苏规定只计增值税
- 承包人答辩：合同未明确，应按全额调差
- 证据：合同材料调差条款原文
- **结果**：协商按70%计算（840万元）

**第3步：达成一致**

| 审减项 | 初审审减 | 答辩后 | 最终审减 |
|---|---:|---:|---:|
| 确定错误 | 460万 | 认可 | 460万 |
| 土方计算规则 | 240万 | 不审减 | 0 |
| 变更签证（补充证据后） | 500万 | 部分认可 | 200万 |
| 材料调差 | 1,200万 | 协商70% | 360万 |
| **合计** | **2,400万** | | **1,020万** |

**最终结果**：
- 审减比例从20%降到8.5%
- 结算金额1.098亿元
- 双方签署结算协议

**经验总结**：
1. 快速认可确定错误项，建立信任
2. 重点答辩有争议项，准备充分证据
3. 最后协商折中方案，不能达成一致的项单独处理

## 五、注意事项

### 5.1 法律和职业道德

- 不虚报工程量、不编造签证、不伪造证据
- 谈判是在合同框架内协商，不是欺诈博弈
- 涉及贿赂、回扣的要求，坚决拒绝并上报

### 5.2 谈判红线

**绝不让步的项**：
- 明显违反合同的要求
- 没有任何依据的要求
- 超出授权范围的要求

**可以让步的项**：
- 理解不同但双方都有依据的项
- 小额争议项（< 合同价0.1%）
- 非原则性的程序问题

### 5.3 谈判记录

**每次谈判后必做**：
1. 整理谈判纪要（当天或次日）
2. 记录双方观点和依据
3. 明确达成一致的项和未达成的项
4. 约定下次谈判时间和议题
5. 双方签字确认
