# 地铁/轨道交通工程造价审核参考

> 适用范围：地铁地下车站、盾构区间、始发/接收井、联络通道、交通导改、管线迁改和施工监测等土建计价与审核场景。
>
> 本文件是审核参考，不是地铁定额、算量软件或设计文件。工程量、单价和措施费必须来自设计图纸、清单、当地计价依据和合同，不得凭空推算。
>
> 默认服务市场为江苏苏州；地区执行时间和地方文件见 `references/standards-index.md` 和 `references/region-jiangsu-shanghai-zhejiang.md`。

## 一、能力边界

- 可以做：清单特征检查、漏项提示、量价交叉验证、变更签证审核、材料调差、进度款和结算审核。
- 不能做：替代地铁算量软件、盾构选型、结构设计、施工组织设计、安全评估、监测方案或法律意见。
- 没有完整图纸、清单、地质资料和合同条款时，只能输出疑似问题、需补资料和人工确认点。
- 地铁工程专业界面复杂，必须区分车站主体、附属结构、盾构区间、轨道、安装、装饰和临时工程。

## 二、项目类型与专业界面

| 类型 | 典型内容 | 审核重点 |
|---|---|---|
| 地下车站 | 围护结构、土方、主体结构、防水、内部结构、出入口、风亭 | 车站规模、开挖深度、围护形式、结构形式、防水等级 |
| 盾构区间 | 盾构掘进、管片、端头加固、联络通道、出土/泥浆 | 盾构直径、地质条件、掘进长度、管片环宽、穿越建构筑物 |
| 始发/接收井 | 围护、土方、结构、端头加固、洞门 | 井深、围护、端头加固、洞门密封 |
| 轨道/安装/装饰 | 轨道、供电、信号、通风空调、给排水、装饰 | 专业界面和合同范围，不与土建重复计取 |
| 临时工程 | 交通导改、管线迁改、临建、围挡、监测 | 是否已包含在措施项目、暂列金额或合同包干范围 |

## 三、车站土建清单特征检查

| 清单项 | 必查特征 | 常见缺失/异常 | 审核提示 |
|---|---|---|---|
| 地下连续墙 | 墙厚、槽深、混凝土强度/抗渗、接头形式、导墙、钢筋笼、泥浆、入岩、检测 | 只写“C35 水下混凝土，墙厚1000mm” | 槽深和入岩影响成槽、钢筋笼和混凝土量；接头形式影响单价 |
| 钻孔灌注桩 | 桩径、桩长、持力层、混凝土、泥浆、钢筋笼、检测、空桩 | 只写桩径和混凝土强度 | 桩长、持力层、空桩和检测要求影响综合单价 |
| 土方开挖 | 土类别、开挖深度、支撑、降水、运距、弃土/回填、工作面/放坡 | 只写“明挖基坑土方” | 土类别、支撑和降水是地铁车站土方的主要差异 |
| 基坑支护 | 支撑/锚索、降水、监测、栈桥、格构柱 | 支撑和监测未列或并入土方 | 支撑体系、栈桥和监测容易被漏项或重复 |
| 主体结构 | 混凝土强度/抗渗、部位、泵送、施工缝/后浇带、模板、钢筋 | 只写“C40 商品混凝土” | 抗渗、部位、施工缝和后浇带影响单价和措施 |
| 防水工程 | 材料、厚度、道数、部位、保护层、变形缝/施工缝 | 只写“SBS 防水卷材” | 厚度、道数和节点防水是常见争议点 |
| 回填/路面恢复 | 材料、压实度、范围、恢复标准 | 只写“回填” | 回填材料和路面恢复标准影响单价 |
| 交通导改 | 范围、期限、次数、围挡、标志、协管 | 只写“按项包干” | 核对是否已包含在措施项目或合同包干范围 |
| 管线迁改 | 管线类型/权属、迁移方式、保护、恢复、协调 | 只写“按实” | 管线权属、迁改方式和恢复标准差异大，不能按项估死 |
| 监测 | 监测项目、频率、报警值、第三方监测 | 未列或只写“按规范” | 车站深基坑和盾构穿越的监测容易被漏项 |
| 临时设施/场地 | 围挡、临建、用水用电、排水 | 只写“临时设施” | 核对临建规模、场地移交和恢复责任 |

## 四、盾构区间清单特征检查

| 清单项 | 必查特征 | 常见缺失/异常 | 审核提示 |
|---|---|---|---|
| 盾构掘进 | 盾构类型/直径、地质条件、掘进长度、埋深、换刀、同步注浆、出土/泥浆、穿越建构筑物/既有线、监测 | 只写“土压平衡盾构 Φ6.4m” | 地质条件、穿越风险、换刀和注浆是单价和索赔的核心 |
| 管片 | 环宽、直径、厚度、混凝土强度/抗渗、配筋、防水、螺栓、预埋件 | 只写“C50 预制管片” | 环宽、配筋、防水和预埋件影响管片单价 |
| 端头加固 | 加固方式、范围、降水、洞门凿除、密封 | 未列或只写“端头加固” | 加固方式（搅拌桩/旋喷/冻结）差异大 |
| 联络通道 | 工法、冻结/矿山法、支护、防水、监测 | 只写“联络通道” | 工法和地质条件是主要风险 |
| 始发/接收井 | 围护、土方、结构、端头加固、洞门 | 与车站或区间界面不清 | 核对井体归属和重复计取 |
| 出土/泥浆 | 运距、处理、环保、弃土场 | 只写“按实” | 运距、泥浆处理和环保要求影响成本 |
| 监测/穿越 | 既有线、管线、建筑物、沉降、报警值 | 未列或只写“监测” | 穿越既有线和建筑物是高风险索赔点 |

## 五、工程量与价格校核

- 地铁工程没有全国统一的“含量指标”可以替代算量；应以设计图纸、工程量计算标准、当地地铁定额/消耗量和 GTJ/GBQ 明细为准。
- 可用以下公式做 sanity check，但不能作为最终工程量：
  - 地连墙面积约等于围护周长乘以墙深，注意接头、导墙和入岩调整。
  - 车站土方体积约等于基坑面积乘以开挖深度，注意支撑、放坡、工作面和回填。
  - 盾构长度按线路里程和区间长度核对；管片环数约等于掘进长度除以环宽，另计负环、楔形环和联络通道影响。
  - 管片混凝土量可按环数、环宽、直径和厚度估算，注意配筋、防水和预埋件。
- 价格校核应使用：
  1. 合同清单已有单价。
  2. 当地城市轨道交通工程计价表/消耗量。
  3. 苏州市工程造价信息或项目所在地信息价。
  4. 供应商报价/企业历史数据（仅作辅助）。
- 不得用房建单方指标直接替代地铁车站或盾构造价。

## 六、合同风险、变更与索赔

| 风险/事件 | 证据链 | 审核重点 |
|---|---|---|
| 地质条件与地勘不符 | 地勘报告、开挖记录、地质素描、照片、监理签认 | 是否属于合同约定风险；是否及时通知；是否影响工期和工法 |
| 盾构穿越既有线/建筑物 | 穿越方案、监测数据、报警记录、停机/加固记录 | 穿越审批、监测频率、报警值、修复责任 |
| 孤石/障碍物 | 地质记录、掘进参数、换刀记录、照片 | 是否可预见；处理方案；台班和材料 |
| 交通导改 | 交通组织方案、交管批复、围挡/标志/协管记录 | 是否已包含在措施项目；期限和次数 |
| 管线迁改 | 管线权属资料、迁改协议、迁改图、验收记录 | 权属、迁改方式、恢复标准、是否由发包人另行委托 |
| 监测 | 监测方案、测点布置、频率、报警值、第三方报告 | 监测项目和频率是否满足规范/合同 |
| 出土/泥浆 | 出土记录、运距、弃土场协议、环保要求 | 运距和处理方式是否变化 |
| 工期延误 | 进度计划、关键线路分析、停工/复工记录 | 工期索赔是否有关键线路影响 |

- 变更签证应有事件事实、书面指令、授权签署、时效、数量、单价和附件证据。
- 证据不足时使用“疑似/待补/人工确认”，不直接认定无效、过期或确定审减。

## 七、材料调差

- 钢筋、商品混凝土通常按合同约定和地方信息价调差；只调超出风险幅度部分。
- 盾构管片、防水材料、盾构耗材是否可调，必须在合同中明确；合同未明确时，不得自行按 5% 或 10% 套用。
- 管片价格通常与配筋、环宽、防水、预埋件和运输距离相关，不能只用混凝土单价推算。
- 调差应注明基准期、施工期、价格来源、风险幅度和含税/不含税口径。
- 江苏项目注意：价差调整只计增值税，不计管理费、利润和措施项目费（以当地规定和合同为准）。

## 八、进度款与结算审核

- 车站和盾构工程量应按合同计量规则、设计图纸和确认的计量资料分列，避免车站、区间、附属结构混算。
- 管片按环计，盾构掘进按米计，注意环宽、负环、楔形环和联络通道的影响。
- 进度款应扣除预付款、甲供材、质保金和其他扣款；未确认变更/索赔不得计入确定应付。
- 结算审核重点：合同内外界面、变更签证、地质/穿越索赔、材料调差、交通导改/管线迁改重复计取、监测漏项、质保金和付款扣回。
- 结算总额与组成合计必须闭合；未说明差异应列为确定问题，要求重新汇总。

## 十一、人工审核点

- 车站/盾构清单特征和工程界面是否符合设计图纸和合同。
- 当地城市轨道交通定额/消耗量的版本、适用范围和执行日期。
- 地质条件、穿越风险、交通导改和管线迁改的责任划分。
- 管片、防水、盾构耗材是否可调差，调差依据是否充分。
- 变更/索赔证据链和时效是否完整。
- 结算金额、付款和质保金扣回是否闭合。
