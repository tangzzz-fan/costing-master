# Excel 输出实践指南

> 本文件说明哪些造价成果适合用 Excel 输出、工作簿怎么组织、公式和证据列怎么设计，以及哪些内容不应以 Excel 作为最终交付。
>
> Excel 是计算和跟踪底稿，不是签章、审批或法律意见的替代品。

## 一、适用性判断

| 类型 | 适用度 | 原因 |
|---|---|---|
| 清单特征、漏项、量价交叉验证 | 高 | 行多，需要筛选、分组和异常标记 |
| 综合单价分析 | 高 | 人材机、定额量、取费、利润、风险均为公式 |
| 投标报价分析、清标 | 高 | 大量清单项，需要偏离度、合价占比和异常筛选 |
| 材料调差 | 高 | 基准期、施工期、风险幅度、加权平均均为公式 |
| 进度款审核 | 高 | 已完产值、支付比例、预付款、质保金、甲供材扣回 |
| 结算审减/审增台账 | 高 | 金额汇总、确定/疑似/待补分类、合计闭合 |
| 变更签证审核 | 高 | 多条签证、证据链、时效、重复计取和状态跟踪 |
| 成本偏差分析 | 高 | 目标/合同/动态/结算成本、偏差金额和比例 |
| 目标成本测算 | 高 | 成本科目、指标、数量、单价、金额和单方校核 |
| 算量指标反查 | 高 | 构件分组、含量反算、偏差比较 |
| 证据索引、需补资料 | 高 | 文件多、证据多，需要编号、位置、可靠性和状态 |
| 地铁清单/索赔证据 | 高 | 车站、区间、盾构清单项多，证据和判断等级需台账化 |
| 结算审核报告正文 | 中 | 台账用 Excel，报告正文和结论用 Word/PDF |
| 管理层摘要 | 中 | 一页纸结论用 Word/PDF/PPT，Excel 只做数据支撑 |
| 二次审核质检报告 | 中 | 检查清单可 Excel，最终结论和签认用 Word/PDF |
| 交付包清单、审核记录 | 中 | 可用 Excel 跟踪，签认页和归档用 Word/PDF 或企业系统 |
| 标准/法规索引 | 低 | 用 Markdown/JSON，便于版本、链接和机器检查 |
| 合同法律意见、评标/审计结论 | 低 | 需要专业人员和正式文件，不用 Excel 作为结论载体 |

## 二、推荐工作簿结构

```text
00_封面与版本    项目、任务、版本、日期、适用标准、地方规则、编制/审核人
01_数据源与口径  合同、清单、信息价、标准版本、含税/不含税、数据日期
02_原始数据      清单/报价/签证/付款原始数据，不合并单元格
03_计算明细      组价、调差、进度款、偏差等公式
04_汇总          合计、偏差、审减/审增、占比
05_问题台账      确定/疑似/待补/人工确认，责任人、状态、截止时间
06_证据索引      证据编号、文件名、页码/行号/工作表、可靠性
07_需补资料      缺失资料、责任人、截止时间
08_质检与审核    二次审核、G1-G6、审核意见、签认记录
```

## 三、公式规范

- 合价 = 工程量 × 综合单价。
- 目标偏差 = 动态成本 − 目标成本。
- 偏差比例 = 偏差金额 / 目标成本。
- 材料调差（涨价）= 调差数量 × (施工期价 − 基准期价 × (1 + 风险幅度))。
- 材料调差（跌价）= 调差数量 × (施工期价 − 基准期价 × (1 − 风险幅度))。
- 进度款 = 已完产值 × 支付比例 − 预付款扣回 − 甲供材扣回 − 质保金 − 其他扣款。
- 质保金 = 本期应付款 × 质保金比例。
- 公式列不要手工覆盖；保留原始数据列和计算列分离。
- 合计行使用 SUM/SUBTOTAL；不要手工输入合计。

## 四、数据验证与格式

- 判断等级统一为“确定/疑似/待补/人工确认”。
- 状态统一为“待处理/处理中/已关闭”。
- 金额使用货币格式，比例使用百分比格式，工程量按专业精度设置小数位。
- 冻结首行，开启筛选；原始数据表不要合并单元格。
- 条件格式标记超目标、超期、未关闭和异常偏离。
- 关键表增加“数据日期”“含税/不含税”“依据来源”列。

## 五、证据与版本

- 每个关键结论对应证据编号；证据索引记录文件名、页码/行号/工作表、可靠性和关联问题。
- 封面记录 Skill 版本、标准索引版本、地方规则版本和数据日期。
- 文件命名建议：`项目简称_交付物_版本_状态_日期`。
- 工作底稿、送审稿、审核稿、定案稿分开；不覆盖旧版本。
- 对外交付前导出 PDF/Word，保留 Excel 作为计算底稿；签认和盖章按企业流程。

## 六、AI 边界

- AI 可以生成表头、公式、台账和证据索引。
- AI 不签认、不盖章、不代替注册造价工程师。
- AI 不把模拟数据当作项目实际数据；缺资料时输出需补资料。
- Excel 中的公式和合计必须可追溯；不能只给结果不给计算依据。

## 七、模板与测试

- CSV 模板：`templates/excel/`
- 测试用例：`test-cases/excel-output.case.md`
- 相关 workflow：清单、计价/投标、材料调差、进度款、结算、成本管理、文件抽取
- 相关模板：`templates/` 下对应 Markdown 模板

## 八、限制

- CSV 模板只提供表头，复杂多 sheet 工作簿需在 Excel 中组装。
- 本仓库暂不包含自动生成 `.xlsx` 的依赖；如需批量生成，可增加 `openpyxl` 构建脚本。
- Excel 不是最终签认文件；对外交付必须经过人工审核、授权和签认。
