# 国内主流造价软件与定额体系

## 一、广联达（Glodon）系列

广联达是国内工程造价领域使用较广的软件平台之一，核心产品线覆盖计量与计价。

### 核心产品

| 软件 | 全称 | 功能 | 适用专业 |
|------|------|------|---------|
| GTJ | 广联达土建算量 | 工程量计算 + 钢筋翻样 | 房屋建筑、装饰、钢结构 |
| GQI | 广联达安装算量 | 安装工程量计算 | 电气、给排水、暖通、消防 |
| GCCP | 广联达云计价 | 清单计价 + 定额计价 | 土建、安装、市政、园林、轨道等 |
| GBQ | 广联达计价（旧版） | 计价（逐步被GCCP替代） | 同上 |
| GMA | 广联达精装算量 | 装饰装修工程量 | 精装修 |

### GTJ 操作要点

- 导入CAD图纸（dwg格式）自动识别构件
- 支持导入Revit模型（RVT格式）进行BIM算量
- 建模顺序：轴网 → 柱 → 梁 → 板 → 墙 → 基础 → 装饰
- 汇总计算后可导出工程量清单和钢筋明细表
- 计算规则可在软件中选择"清单规则"或"定额规则"

### GCCP 操作要点

- 新建项目 → 选择定额库（按省份选择）→ 选择专业（土建/安装/市政等）
- 导入Excel格式的工程量清单（广联达格式，非通用Excel）
- 套定额：在定额库中搜索定额编号或关键词
- 调价：可手动调整人工单价、材料单价，也可导入当地信息价文件（.xxj格式）
- 导出：可导出综合单价分析表、工程量清单计价表、规费税金表（旧版软件用词）等

### AI 对接导出建议

从 GTJ/GCCP 等软件导出给 AI 检查时，建议同时提供以下表格或截图：

| 资料 | 用途 |
|---|---|
| 项目设置截图 | 确认地区、定额库、费用文件、税率、计价模板 |
| 分部分项清单计价表 | 检查清单五要素、工程量、综合单价、合价 |
| 综合单价分析表 | 检查人工、材料、机械、管理费、利润、风险费 |
| 定额子目明细表 | 区分清单工程量和定额工程量，检查套项和换算 |
| 人材机汇总表 | 检查材料价格来源和主材异常 |
| 措施/其他项目/税金表 | 检查应足额计取费用、暂列暂估、增值税口径 |

常见风险：

- 清单工程量、定额工程量、主材工程量字段混用。
- 软件模板保留“规费税金”等旧称，但实际费用内容已按新口径处理。
- 导出 Excel 删除了隐藏列、公式或项目设置，导致 AI 无法复核来源。

导出包不完整、表头不一致或需要把问题回填软件时，按 `workflows/software-export-review.md` 执行，使用 `input-specs/software-export-package.md` 和 `templates/software-issue-return-list.md`；`scripts/check_software_export.py` 可对导出的 Excel/CSV 做结构、编码、量价、合计、单位和 2024 版费用口径体检。Skill 不读取或修改 `.GBQ/.GCCP/.24jz/.24jk/.24jt` 等源文件。

## 二、鲁班（Luban）系列

鲁班是国内较早的BIM+造价一体化平台，长三角地区市场份额较高。

| 软件 | 功能 |
|------|------|
| 鲁班土建 | 土建工程量计算 |
| 鲁班钢筋 | 钢筋翻样与计算 |
| 鲁班安装 | 安装工程量计算 |
| 鲁班造价 | 计价软件 |
| Luban BIM | BIM平台（碰撞检测、进度模拟等） |

**鲁班 vs 广联达差异点：**
- 鲁班更侧重BIM全生命周期应用
- 广联达在计价端（GCCP）市场份额更高
- 鲁班在上海/浙江/江苏有地域优势

## 五、定额体系

### 5.1 定额层级

```
全国统一基础定额（住建部发布，基础标准）
  ├── 省级建设工程计价定额（各省住建厅发布，实际执行依据）
  │     ├── 建筑与装饰工程消耗量定额
  │     ├── 安装工程消耗量定额
  │     ├── 市政工程消耗量定额
  │     ├── 园林绿化工程消耗量定额
  │     └── 城市轨道交通工程概算定额
  └── 企业定额（大型施工企业内部使用，市场化方向）
```

### 5.2 主要省份定额体系

> 本仓库默认服务江苏苏州市场，优先江苏/苏州、上海、浙江现行文件；其他省份仅作对比。表中版本和施行日期以项目所在地公告为准，详细执行时间和官方来源见 `references/standards-index.md` 和 `references/region-jiangsu-shanghai-zhejiang.md`。

| 省份 | 定额/计价依据名称 | 特点 |
|------|------------|------|
| 江苏（苏州） | 2026版江苏省建设工程消耗量指标、2026版江苏省建设工程费用参考（2026-06-01起执行；旧项目按原规定） | 苏州本地：苏安码、总承包服务费分列、最高投标限价编制说明、价差调整口径 |
| 上海 | 上海市建设工程工程量清单计价应用规则（2025版，2026-01-01起施行；预算定额更新待核对） | 国家2024版+上海应用规则；数据文件标准 Ver2.0-2025 |
| 浙江 | 浙江省建设工程计价依据（2025版，2026-11-01起施行；2018版过渡至2026-10-31） | 八部计价成果；按招标/合同日期划断 |
| 北京 | 北京市建设工程计价依据（2021版） | 人工+机械为管理费取费基数 |
| 广东 | 广东省建设工程计价依据（2018版） | 人工费为管理费取费基数；动态人工费调整系数 |
| 深圳 | 深圳市建设工程计价标准 | 独立于广东省定额 |
| 四川 | 四川省建设工程工程量清单计价定额（2020版） | 明确海拔高度调整系数 |
| 重庆 | 重庆市建设工程计价定额（2018版） | 山地建筑增加费有专门规定 |

> 城市轨道交通工程另有专项计价依据：江苏 2013 计价表、上海 2025 应用规则/历史轨道交通预算定额、浙江 2025 版城市轨道交通工程定额；详见 `references/metro-rail-transit.md`。

### 5.3 定额子目结构解读

每个定额子目包含：

```
定额编号: 1-1-1（专业-分部-子目）
项目名称: 人工挖土方
工作内容: 包括挖土、抛土、修底、修边
单位: 100m³
消耗量:
  ├── 人工: 综合工日 X个工日
  ├── 材料: 无
  └── 机械: 无
基价: 人工工日×人工单价 + ∑(材料量×材料单价) + ∑(机械台班×台班单价)
```

### 5.4 定额计价到市场价的转换

GB/T 50500-2024 推行市场化后，从定额价到市场价的转换路径：

1. **直接采用市场价**（钢筋、商品砼等有活跃市场的材料）—— 首推
2. **定额基价 × 调整系数**（根据造价信息发布的调价系数）
3. **定额消耗量 × 市场单价**（定额消耗量保留，替换单价来源）
4. **企业实际成本数据替换**（大型企业采用企业定额）

## 七、实务操作建议

1. **新项目开工**：首先确认项目所在地，并提示用户上传对应省/市定额库版本、费用文件和软件导出的项目设置截图
2. **定额选择**：如工程所在地为深圳，应优先用深圳定额而非广东省定额；如无本地定额，可用省级定额，并在输出中说明依据来源
3. **信息价订阅**：及时获取最新的当地造价信息；未上传信息价文件时，只能输出需补资料清单和价格校核思路
4. **软件数据互通**：广联达GTJ算量 → 导出Excel → 导入GCCP计价是最常见的流程；导出后按 `workflows/software-export-review.md` 做包体检和问题回填
5. **定额争议**：如定额中无适用子目，可借用类似子目并申请定额解释，或采用市场询价+补充定额方式处理

## 八、电子招投标数据交换与软件回填（江苏 2026）

### 8.1 官方依据

江苏省《建设工程电子招标投标造价数据交换标准》自 2026-06-01 起执行，替代原《建设工程电子招投标专业工具软件数据交换标准》（DGJ32/TJ 93-2016）。本标准适用于执行江苏省建设工程计价依据的电子招标投标造价文件的数据生成、输出和交换。

| 项目 | 内容 |
|---|---|
| 标准名称 | 建设工程电子招标投标造价数据交换标准 |
| 状态 | 现行；2026-06-01 起执行（以江苏省建设工程招标网和交易平台公告为准） |
| 替代文件 | DGJ32/TJ 93-2016《建设工程电子招投标专业工具软件数据交换标准》 |
| 官方来源 | [江苏省建设工程招标网标准文本](http://jszb.com.cn/JSZB/UploadFile/20260414092904254.pdf) |
| 文件校验 | SHA256 `b985cad54ab733c6b0b83714219d2dceb2cef43c6e8ea951970760abb9856cd1`（2026-10-31 下载） |
| 审核状态 | 已核对文本条款，执行时间和地方适用性待人工审核；见 `references/standards-index.md` |

### 8.2 文件后缀

| 后缀 | 用途 | 生成方 |
|---|---|---|
| `.24jz` | 招标工程量清单 | 招标人或其委托的计价软件 |
| `.24jk` | 最高投标限价 | 招标人或其委托的计价软件 |
| `.24jt` | 投标报价 | 投标人的计价软件 |

后缀名由《建设工程工程量清单计价标准》GB/T 50500 的年份加 `jz`、`jk`、`jt` 构成；2024 版对应 `.24jz`、`.24jk`、`.24jt`。

### 8.3 文件格式和精度

- XML 文件头应为 `<?xml version="1.0" encoding="utf-8"?>`。
- 经济标元素的版本字段 `Version` 固定为 `4.0`。
- XML 文件应通过《江苏省建设工程电子招标投标造价数据交换标准.XSD》校验。
- 清单工程量最多 6 位小数；金额最多 2 位；费率最多 4 位；人材机单价最多 4 位。
- 金额以元为单位；费率、风险系数按百分比存储，例如 `10` 表示 `10%`。
- 配合比材料应分析出组成材料；特殊字符按 XML 转义规则存储。
- 招标文件和投标文件应先去除不可见字符和空格，必填字段不得为空。

### 8.4 一致性校验项

标准 6.0.1 要求专业工具软件对招标文件和投标文件的清单内容做一致性校验，主要包括：

| 校验对象 | 校验内容 |
|---|---|
| 单项工程 | 单项工程编号、名称 |
| 单位工程 | 单位工程编号、名称 |
| 分部工程清单 | 项目编码、名称、项目特征、单位、工程量 |
| 措施项目明细 | 项目编码、名称、工作内容、单位、计价方式、有特殊规定的费率 |
| 其他项目清单计价表 | 序号、名称、项目类别 |
| 暂列金额表明细 | 序号、名称、暂定金额、计价方式 |
| 专业工程暂估价表明细 | 序号、名称、不含税价格、增值税、含税价格 |
| 计日工表明细 | 编号、名称、单位、暂定数量 |
| 总承包服务费计价表明细 | 序号、名称、计价方式 |
| 材料工程设备暂估单价表明细 | 编号、名称、规格型号、单位、暂估单价、备注 |
| 发包人提供材料一览表明细 | 编号、名称、规格型号、单位、单价、有效损耗率、交货方式、送达地点、承包人负责安装 |
| 承包人提供价格信息调差法材料明细 | 编号、名称、规格型号、单位、基准价、风险系数 |
| 承包人提供价格指数调差法材料明细 | 编号、名称、规格型号、单位、基本价格指数 F0、风险系数、类别 |
| 增值税计价表明细 | 税率 |

标准 6.0.3 还要求：措施项目可增项；安全生产应为一条；人材机汇总表应包括暂估材料、发包人提供材料、承包人提供可调价主要材料，且编号、名称、规格型号、单位、单价保持一致。

### 8.5 计算规则

标准 6.0.4 规定的主要计算规则：

| 数据节点 | 计算规则 |
|---|---|
| 工程项目总造价 | 各单项工程造价之和 |
| 单项工程造价 | 单项工程下各单位工程造价之和 |
| 单位工程总价 | 单位工程各项费用之和，扣除发包人提供材料费（不含保管费，从发包人提供材料一览表明细合价列汇总） |
| 分部分项工程项目费 | 清单项明细合计 |
| 措施项目费 | 措施项明细合计 |
| 人材机汇总表明细合价 | 单价×数量 |
| 综合合价 | 综合单价×数量 |
| 综合单价 | 人工费＋材料费＋机械费＋管理费＋利润 |
| 费率计价措施项金额 | 取费基数×费率 |
| 其他项目合计 | 其他项目明细合计 |
| 计日工合计 | 人工小计＋材料小计＋机械小计 |
| 暂列金额合计 | 合同价格调整暂列金额＋未确定工程暂列金额＋未确定服务暂列金额＋未确定其他暂列金额 |
| 专业工程暂估价合计 | 专业工程暂估价明细含税价格合计 |
| 总承包服务费合计 | 发包人提供材料小计＋专业分包工程小计＋直接发包的专业工程小计 |
| 计日工明细合价 | 综合单价×暂定数量 |
| 暂估材料合价 | 暂估单价×暂估数量 |
| 发包人提供材料合价 | 单价×数量 |
| 含税价格 | 不含税价格＋增值税 |

注：标准原文中“措施项目费＝措施项明细合计”“单位工程总价扣除发包人提供材料费”等规则，与部分地区旧版费用口径可能不同；项目执行时以现行标准、地方费用文件和合同约定为准。

### 8.6 软件导出、体检、回填、复检

推荐闭环：

1. **导出**：在计价软件中导出分部分项清单计价表、措施表、其他项目表、人材机汇总、综合单价分析和项目设置截图；保留标题行、工作表名和原始小数位。
2. **体检**：运行 `python3 scripts/check_software_export.py <文件> --standard 2024 --out 问题回填.csv --md 体检报告.md`；检查编码、五要素、量价、合计、单位、精度和 2024 版费用口径。
3. **回填**：把问题按“单位工程—工作表—软件行号—清单编码”整理到 `templates/software-issue-return-list.md`，交造价人员在原软件中修改。
4. **复检**：重新导出新版本，使用同一命令复检；对比问题关闭情况，保留修改前后文件和差异记录。
5. **平台校验**：江苏项目由软件生成 `.24jz/.24jk/.24jt`，再通过软件/交易平台的 XSD 校验和清标工具检查；Skill 的 Excel 体检不能替代平台校验。

### 8.7 边界和保密

- Skill 不读取、不修改 `.GBQ/.GCCP/.24jz/.24jk/.24jt` 等专有文件；只处理导出的 Excel/CSV。
- 不直接修改招标人提供的清单项、暂列金额、暂估价、增值税税率和安全生产措施费费率；投标时擅自改变可能导致无效投标。
- 不把自动体检结果写成评标结论、废标结论、低于成本认定或法律意见。
- 未公开招标文件、最高投标限价、投标报价、合同和供应商报价，不得上传到未经企业批准的公共 AI 环境；上传前脱敏项目名称、投标人名称、联系人和账号信息。
- 正式投标、清标、评标和结算以交易平台、软件 XSD 校验、评标委员会、合同和注册造价工程师判断为准。
