# 建筑安装工程费用组成详解

> 本文件是费用组成和取费口径的主文件；清单编制、综合单价组价和不平衡报价分析见 `references/boq-and-pricing.md`。

## 一、费用四级结构（GB/T 50500-2024）

```
建筑安装工程费
  │
  ├── 第一级：分部分项工程费
  │     └── ∑(分部分项工程量 × 综合单价)
  │
  ├── 第二级：措施项目费
  │     ├── 安全生产措施费、文明施工费、环境保护费、临时设施费
  │     └── 其他措施项目费
  │
  ├── 第三级：其他项目费
  │     ├── 暂列金额
  │     ├── 暂估价
  │     ├── 计日工
  │     └── 总承包服务费
  │
  └── 第四级：税金
        └── 增值税（单独计列）
```

*注：GB/T 50500-2024 不再将“规费”作为独立费用项列项。原规费中的社会保险费、住房公积金、工会经费、职工教育经费等，按人员归属分流：生产工人的计入人工费，管理人员的计入企业管理费；附加税费计入企业管理费。具体分项以标准正式文本和项目所在地费用文件为准。*

## 二、综合单价拆解

### 综合单价 = 人工费 + 材料费 + 施工机具使用费 + 企业管理费 + 利润 + 风险费

### 2.1 人工费（生产工人口径）

GB/T 50500-2024 中生产工人的人工费包含：
- 计时/计件工资
- 奖金
- 津贴补贴
- 加班加点工资
- 特殊情况下支付的工资
- **社会保险费**（原规费项，已并入）
- **住房公积金**（原规费项，已并入）
- 工会经费
- 职工教育经费
- 劳动保护费
- 职工福利费

> 管理人员的工资、社保、公积金、工会经费、职工教育经费、劳动保护费、职工福利费等，计入企业管理费（见 2.4）。

### 2.2 材料费

| 构成 | 说明 |
|------|------|
| 材料原价 | 出厂价或市场供应价 |
| 运杂费 | 从来源地到工地仓库的运输、装卸等费用 |
| 运输损耗费 | 运输途中的合理损耗 |
| 采购及保管费 | 采购、验收、仓储、保管费用(一般2-2.5%) |
| 检验试验费 | 一般鉴定、检查费用（不含新结构/新材料试验费） |

### 2.3 施工机具使用费

- 折旧费
- 大修理费
- 经常修理费
- 安拆费及场外运费
- 人工费（机上操作人员）
- 燃料动力费
- 税费（车船使用税等）

### 2.4 企业管理费

**取费基数**（各省不同）：
- 以人工费为基数（广东、四川等）
- 以人工费+机械费为基数（北京、上海、浙江等）

**取费比例（经验参考）**：管理费按上述取费基数计算；折算为占分部分项工程费的比例，房建约 3-8%、市政约 5-10%，具体以当地费用文件为准。

**包含内容**：
- 管理人员工资
- 办公费
- 差旅交通费
- 固定资产使用费
- 工具用具使用费
- 劳动保险和福利费
- 劳动保护费
- 社会保险费、住房公积金（管理人员）
- 工会经费和职工教育经费
- 财产保险费
- 财务费（利息支出等）
- 税金（房产税/车船税等，不含增值税）
- 其他（审计费/法律顾问费/业务招待费等）

### 2.5 利润

- 取费基数：同管理费取费基数
- 利润率（经验参考）：5-7%（房建），7-10%（市政/安装），按当地费用文件和企业报价策略确定

### 2.6 风险费

- 材料价格波动（合同约定范围内由承包人承担的部分）
- 施工条件变化风险（可预见的常规风险）
- 不包括：法规变化、不可抗力、发包人指令变更

## 三、措施项目费详解

### 3.1 安全生产措施费及原安全文明施工费拆分

2024 版将原“安全文明施工费”拆分为四项，分别列项：

| 费用项目 | 主要内容 | 计价/竞争属性 |
|---|---|---|
| 安全生产措施费 | 安全防护、三宝四口五临边、临时用电及消防、安全标识、检测检验、安全培训、应急演练、安全生产责任保险等 | 按国家/地方规定足额计取、专款专用；是否可竞争按招标文件和地方规定 |
| 文明施工费 | 围挡、场地硬化绿化、标牌、保洁、卫生设施、防暑降温、临时排水等 | 单独列项，按招标文件/地方规定 |
| 环境保护费 | 扬尘控制、噪声防治、污水排放处理、垃圾清运、裸土覆盖、密闭运输等 | 单独列项，按招标文件/地方规定 |
| 临时设施费 | 办公/生活区临时建筑、临时用电配电线路/配电箱等 | 单独列项，按招标文件/地方规定 |

*注：具体名称、费率和竞争属性以项目所在地现行费用文件和招标文件为准；原“安全文明施工费”综合费率不再直接套用到 2024 版。*

### 3.2 其他措施项目费（可竞争）

| 项目 | 计算方式 | 是否包干 |
|------|---------|---------|
| 脚手架工程费 | 按面积或按项 | 一般包干 |
| 混凝土模板及支架 | 按混凝土量或按项 | 一般包干 |
| 垂直运输费 | 按建筑面积或工期 | 一般包干 |
| 大型机械进出场及安拆 | 按台次 | 可调 |
| 施工排水降水 | 按实计或按项包干 | 视约定 |
| 已完工程保护费 | 按项 | 一般包干 |
| 高层建筑增加费 | 按面积或按百分比 | 一般包干 |
| 冬雨季施工增加费 | 分部分项费×费率 | 一般包干 |
| 夜间施工增加费 | 按夜间施工天数 | 可调 |

## 四、其他项目费详解

### 4.1 暂列金额

| 设计阶段 | 行业经验参考比例 |
|---------|---------|
| 初步设计阶段 | 分部分项工程费的10-15% |
| 施工图设计阶段 | 分部分项工程费的5-10% |

> 以上比例为行业经验参考，具体由招标人根据工程复杂程度、设计深度和风险确定；计费基数是否仅含分部分项工程费，以招标文件和当地规定为准。

**结算处理**：暂列金额余额归发包人所有，如有不足由发包人另行追加。

### 4.2 暂估价

| 类型 | 列项方式 | 结算处理 |
|------|---------|---------|
| 材料暂估价 | 在分部分项清单中直接标注暂估单价 | 确认单价后调整综合单价 |
| 设备暂估价 | 同上 | 同上 |
| 专业工程暂估价 | 在其他项目清单中列出暂估总价 | 确认后调整合同价 |

### 4.3 计日工

- 人工：按暂定数量×投标人报的计日工单价
- 材料：按暂定数量×投标人报的计日工材料单价
- 机械：按暂定数量×投标人报的计日工机械单价
- 结算：按发包人实际签证确认的数量

### 4.4 总承包服务费

**服务范围**：
- 对发包人直接发包的专业工程进行总承包管理和协调
- 对甲供材进行保管和配合（如需承包人保管，则计取保管费）

**计价方式**：
- 总价方式：按服务内容报价
- 费率方式：按分包工程造价的百分比（一般1-3%）

## 五、税金（增值税）

### 5.1 建筑业增值税

| 计税方式 | 适用情况 | 税率 |
|---------|---------|------|
| 一般计税 | 一般纳税人 | 9%（销项税，进项税可抵扣） |
| 简易计税 | 小规模纳税人/清包工/甲供工程/老项目 | 3%（全额征收，不可抵扣） |

### 5.2 GB/T 50500-2024 增值税处理

- **综合单价不含增值税**
- 在单位工程费汇总表中单独列示"增值税"
- 增值税 = [分部分项工程费 + 措施项目费 + 其他项目费（专业工程暂估价除外）] × 增值税税率
- 专业工程暂估价为含税价，不再计入增值税计税基数，避免重复计税；材料暂估价通常为不含税价，仍计入税前造价。
- 附加税（城建税、教育费附加、地方教育附加）已并入企业管理费

## 六、应足额计取费用汇总

以下费用应按国家/地方规定足额计取，投标人不得擅自下浮或优惠：

| 费用 | 依据/说明 |
|----------|------|
| 安全生产措施费 | 按国家安全生产法规和省级主管部门规定足额计取、专款专用；是否可竞争按招标文件和地方规定 |
| 增值税 | 税法，按国家规定税率全额计取 |

*注1：GB/T 50500-2024 将原2013版“规费”（社会保险费、住房公积金等）按人员归属并入人工费/企业管理费，不再作为独立费用项。*
*注2：2024 标准将原“安全文明施工费”拆分为安全生产措施费、文明施工费、环境保护费、临时设施费四项；安全生产措施费是其中一项，不再与原“安全文明施工费”整体等同。*
